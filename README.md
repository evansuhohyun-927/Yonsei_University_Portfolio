## 🗂 폴더 구조
```
Yonsei_University_Portfolio/
├── README.md                 ← 전체 목차 (자동 갱신)
├── <연도>/
│   └── <N학기>/
│       ├── README.md         ← 학기 과목 목록 (자동 갱신)
│       ├── 수강현황.png
│       ├── 교과/
│       │   └── <과목코드_과목명>/
│       └── 비교과/           ← 대내외활동·비교과 프로그램 (필요할 때 생성)
├── templates/                ← 주차 요약 등 노트 템플릿
└── scripts/course.py         ← 과목 폴더 생성 · 목차 갱신
```

## 📁 과목 폴더 구성
| 폴더 | 용도 |
|---|---|
| `수업요약/` | 주차별 요약 노트 (`templates/주차요약_템플릿.md` 사용) |
| `과제/` | 과제 제출본·피드백 |
| `시험대비/` | 중간/기말 정리, 예상문제, 오답노트 |
| `실험보고서/` | 실험 과목 전용 (예: 일반생물학및실험) |

각 과목의 `README.md`에는 과목 정보와 **1–16주차 요약 표**(8주차 중간, 16주차 기말)가 들어 있습니다.

> 📌 공개용 리포입니다. 강의 슬라이드·시험지 등 교수님 저작물 원본은 포함하지 않고, 직접 작성한 요약·과제·시험 정리만 올립니다.

## ➕ 새 학기 · 새 과목 추가하기
```bash
# 새 과목 (폴더 + README + 목차 자동 갱신)
python3 scripts/course.py new --year 2027 --semester 1 \
    --code BIO2001.01-00 --name "생화학(1)" --prof 홍길동

# 실험 과목: 추가 폴더 지정
python3 scripts/course.py new ... --extra 실험보고서

# 실기 과목: 하위 폴더 없이 README만
python3 scripts/course.py new ... --minimal

# 비교과 활동
python3 scripts/course.py new ... --type 비교과

# 폴더를 직접 옮기거나 course.json을 고친 뒤 목차만 다시 만들기
python3 scripts/course.py index
```
