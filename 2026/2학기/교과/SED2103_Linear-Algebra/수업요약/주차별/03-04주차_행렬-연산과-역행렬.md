## 이론: Ch3-1 §3.1–3.3 (p. 1–46)

Ax는 **A의 열들의 linear combination**이고, AB는 각 열 Abⱼ를 모은 행렬이에요 (Def 3.1.4, 3.1.6). 곱셈은 교환법칙이 성립하지 않아요.

```math
Ax = x_1a_1 + \cdots + x_na_n, \qquad (AB)_{ij} = a_{i1}b_{1j} + \cdots + a_{is}b_{sj}
```

```math
A^{-1} = \frac{1}{ad-bc}\begin{bmatrix} d & -b \\ -c & a \end{bmatrix}, \qquad (AB)^{-1} = B^{-1}A^{-1}, \qquad (AB)^T = B^TA^T
```

| 개념 | 핵심 |
|---|---|
| Elementary matrix (Thm 3.3.1–3.3.2) | 행 연산 1회 = E를 왼쪽에 곱하기. E는 항상 가역 |
| Inverse algorithm | \[A \| I\] → \[I \| A⁻¹\]. 왼쪽에 zero row가 생기면 비가역 |
| Thm 3.3.9 (Unifying) | RREF = I ⇔ 가역 ⇔ Ax = 0은 trivial only ⇔ 모든 b에 유일해 |
| Trace (Thm 3.2.12) | tr(AB) = tr(BA). tr(A)tr(B)와는 다름 |

예: A = \[1 2 3; 2 5 3; 1 0 8\]의 역행렬은 \[−40 16 9; 13 −5 −3; 5 −2 −1\]이에요 (Ex 3).

## MATLAB 세션: M3 Vectors and Matrices (3주차)

벡터·행렬을 만들고 인덱싱하고 모양을 바꿔요. MATLAB은 **column-major**라 단일 인덱스와 `reshape`가 열 순서로 움직여요.

- `3:2:10` → \[3 5 7 9\], `linspace(0,1,5)` → \[0 .25 .5 .75 1\]
- `m(i,j)`, `m(:,j)`, `m(k)`: \[2 4 6; 1 3 5\]에서 `m(3)` = 4
- `size`, `numel`, `length`: 3×4 행렬이면 \[3 4\], 12, 4
- `reshape(m,2,6)`, `fliplr`, `repmat`, `mat(:,2) = []`(열 삭제)

## MATLAB 세션: M4 Operations (4주차)

점(`.`)이 붙으면 성분별, 없으면 선형대수 연산이에요. 집계 함수는 행렬에서 열별로 동작해요.

| 명령 | 결과 | 함정 |
|---|---|---|
| `max([3 8 1; 6 2 9])` | \[6 8 9\] (열별) | 전체 최댓값은 `max(max(m))` |
| `(2:5).*[1 0 2 3]` | \[2 0 8 15\] | `A^2` = A\*A, `A.^2` = 성분 제곱 |
| `v(v>5)`, `find(v>5)` | 값 / 위치 | `sum(v>5)` = 개수 |
| `[4 5 6]*[1;2;3]` | 32 (내적) | 순서를 바꾸면 3×3 outer product |
| `cross([1 0 0],[0 1 0])` | \[0 0 1\] | R³ 전용 |
