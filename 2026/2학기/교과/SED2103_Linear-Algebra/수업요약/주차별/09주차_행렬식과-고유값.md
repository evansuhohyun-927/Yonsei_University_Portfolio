## 이론: Ch4 §4.1, 4.2, 4.4 (p. 1–32)

det(A) ≠ 0이면 A는 가역이에요. Eigenvalue는 det(λI − A) = 0의 해이고, eigenvector는 (λI − A)x = 0의 0이 아닌 해예요.

```math
\det A = a_{i1}C_{i1} + \cdots + a_{in}C_{in}, \qquad C_{ij} = (-1)^{i+j}M_{ij}
```

```math
Ax = \lambda x \iff \det(\lambda I - A) = 0, \qquad \det A = \lambda_1\cdots\lambda_n, \qquad \mathrm{tr}\,A = \lambda_1 + \cdots + \lambda_n
```

| 성질 | 핵심 |
|---|---|
| Cofactor expansion | 0이 많은 행·열을 고릅니다. 삼각행렬은 대각 성분의 곱 |
| 행 연산 | 교환 → 부호 반대, k배 → k배, 배수 더하기 → 불변 |
| det(AB) = det(A)det(B) | det(A + B)는 일반적으로 성립하지 않아요 |
| Block triangular | 특성다항식 = 대각 블록들의 특성다항식 곱 |
| Aᵏ | Ax = λx ⇒ Aᵏx = λᵏx (같은 eigenvector) |

## MATLAB 세션: M6 LU decomposition과 계산량 (MATLAB Week 6)

MATLAB의 `lu`는 partial pivoting을 써서 **PA = LU**를 돌려줘요. b에도 P를 곱한 뒤 삼각 시스템 두 개를 풀어요.

```math
PA = LU \;\Rightarrow\; Ly = Pb, \quad Ux = y
```

- `[L,U,P] = lu(A)`: L의 대각은 1, P는 permutation matrix. `[L,U] = lu(A)`만 쓰면 L = PᵀL이라 삼각행렬이 아닐 수 있어요.
- `y = L\(P*b); x = U\y`. P를 빼먹으면 틀려요.
- 계산량: n이 2배면 약 8배. LU 한 번 (2/3)n³, 이후 b마다 2n².
