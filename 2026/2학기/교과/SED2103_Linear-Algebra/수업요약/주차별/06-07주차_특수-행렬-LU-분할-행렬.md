# 6–7주차 — 특수 행렬, LU, 분할 행렬

> **이번 주 개념 노트** [3.6 Special forms](../Ch3-2_Subspaces-Geometry-LU/3.6_Special-forms.md) · [3.7 LU decomposition](../Ch3-2_Subspaces-Geometry-LU/3.7_LU-decomposition.md) · [3.8 Partitioned matrices](../Ch3-2_Subspaces-Geometry-LU/3.8_Partitioned-matrices.md)  
> **MATLAB 노트** 세션 없음

## 이론: Ch3-2 §3.6–3.8 (p. 36–66)

A = LU로 한 번 분해해 두면 Ax = b는 삼각 시스템 두 개로 풀려요. 행 교환 없이 Gaussian elimination이 되면 LU가 존재해요 (Thm 3.7.2).

```math
Ax = b \;\Rightarrow\; L(Ux) = b: \quad Ly = b \ (\text{forward}), \quad Ux = y \ (\text{back})
```

| 종류 | 핵심 |
|---|---|
| Diagonal | D⁻¹ = diag(1/dᵢ), Dᵏ = diag(dᵢᵏ) |
| Triangular (Thm 3.6.1) | 가역 ⇔ 대각 성분이 모두 0이 아님 |
| Symmetric (Thm 3.6.2–3.6.4) | AB가 symmetric ⇔ AB = BA. AAᵀ, AᵀA는 항상 symmetric |
| Nilpotent (Thm 3.6.6) | Aᵏ = 0이면 (I − A)⁻¹ = I + A + ⋯ + Aᵏ⁻¹ |
| LU 절차 (p.56) | U는 leading 1. L 대각 = leading 1을 만든 수의 역수, 아래 = 0을 만든 배수의 부호 반대 |
| Partitioned (§3.8) | block diagonal이면 각 블록의 역행렬로 A⁻¹ |

계산량: elimination과 LU는 약 (2/3)n³ flops, 이후 b 하나당 약 2n², \[A | I\]로 역행렬을 만들면 약 2n³이에요.

예: Ex 1은 y = (1, 5, 2), x = (2, −1, 2).

## MATLAB 세션: 없음

이 기간에는 별도 MATLAB 세션 파일이 없어요. LU의 MATLAB 실습(`[L,U,P] = lu(A)`)은 9주차 M6에서 다뤄요.
