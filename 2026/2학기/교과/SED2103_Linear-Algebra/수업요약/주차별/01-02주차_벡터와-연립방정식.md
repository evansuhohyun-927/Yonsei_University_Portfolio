## 이론: Ch1 Vectors (p. 1–25)

벡터는 크기와 방향을 가진 양이고, Rn에서는 성분별로 더하고 스칼라배해요. 내적 하나로 길이, 각도, 직교, 정사영을 모두 계산해요.

```math
\|v\| = \sqrt{v_1^2 + \cdots + v_n^2}, \qquad u\cdot v = u_1v_1 + \cdots + u_nv_n, \qquad \cos\theta = \frac{u\cdot v}{\|u\|\|v\|}
```

```math
\mathrm{proj}_a u = \frac{u\cdot a}{\|a\|^2}\,a, \qquad |u\cdot v| \le \|u\|\|v\|, \qquad \|u+v\| \le \|u\| + \|v\|
```

- **Linear combination** w = c₁v₁ + ⋯ + cₖvₖ (Def 1.1.8). 뒤의 span, Ax의 출발점이에요.
- **직선** x = x₀ + tv, **평면** n·(x − x₀) = 0 또는 x = x₀ + t₁v₁ + t₂v₂ (§1.3).
- 함정: (u·v) + w처럼 스칼라와 벡터를 더하는 식은 정의되지 않아요 (p.21 Discussion).

## 이론: Ch2 Systems of Linear Equations (p. 1–33)

연립방정식의 해는 항상 0개, 1개, 무한히 많음 중 하나예요 (Thm 2.1.1). 첨가행렬을 elementary row operation으로 REF/RREF까지 줄여서 읽어요.

| 개념 | 핵심 |
|---|---|
| REF / RREF | leading 1, zero row는 아래. RREF는 유일하고 REF는 아님 |
| Gauss–Jordan / Gaussian | 전진+후진 소거 / 전진 + back substitution |
| Free variable | leading 1이 없는 열의 변수. 개수 = n − r (Thm 2.2.2) |
| Homogeneous Ax = 0 | trivial 해 항상 존재. 미지수 > 식이면 무한해 (Thm 2.2.3) |
| Polynomial interpolation | x가 다른 n점 → 차수 ≤ n−1 다항식 유일 (Thm 2.3.1), Vandermonde 계 |

예: (1, 3), (2, −2), (3, −5), (4, 0)을 지나는 다항식은 p(x) = 4 + 3x − 5x² + x³이에요 (Ch2 Ex 7). 중간고사 Q5, Q12, Q14가 이 계산이었어요.

## MATLAB 세션: M1 Introduction I (1주차)

Command Window에서 바로 계산하고, `=`로 변수에 대입하고, 연산자 우선순위대로 계산해요.

- 우선순위: `()` → `^` → 음수화 → `* / \` → `+ −`. `3+4*2^2` = 19
- `;`는 출력만 숨겨요. `clc`는 화면만, `clear`는 변수를 지워요.
- `3e5` = 300000 (e는 자연상수가 아니에요). `format long`, `format rat`은 표시만 바꿔요.
- 변수명은 문자로 시작하고 대소문자를 구분해요. 하이픈은 빼기로 읽혀요.

## MATLAB 세션: M2 Introduction II (2주차)

내장 상수, 난수, 정수 타입, 논리 연산, 수학 함수의 규칙을 다뤘어요.

| 명령 | 동작 | 함정 |
|---|---|---|
| `rand`, `a+(b-a)*rand` | (0,1) → (a,b) 균등 실수 | `rand(3)`은 3×3 행렬 |
| `randi([5,10])`, `randi(10)` | 양 끝 포함 정수 | `randi(10)`은 1–10 (0 없음) |
| `int8(200)` | 127로 saturate | 소수는 반올림 |
| `sin(pi)` / `sind(30)` | 라디안 / 도 | `sin(pi)` = 1.2246e−16, 0이 아님 |
| `fix(-2.7)` / `floor(-2.7)` | −2 / −3 | 음수에서 다름 |
| `rem(-7,3)` / `mod(-7,3)` | −1 / 2 | 부호가 다름 |
