- **교환·결합·분배** — 순서 바꾸기, 묶는 위치 바꾸기, 2(3+4) = 2·3 + 2·4
- **왜 교환이 안 되나** — AB는 B를 먼저 적용하고 A를 적용합니다. 양말 → 신발과 신발 → 양말은 다릅니다.
- **Inverse** — 5에 1/5을 곱하면 1이듯 AA⁻¹ = I. 정사각 행렬에서만 정의됩니다.
- **Determinant의 그림** — 2×2 행렬은 넓이 1인 정사각형을 평행사변형으로 바꿉니다. 그 넓이가 |ad − bc|입니다.

</details>

### Thm 3.2.1

(a) A+B = B+A (b) A+(B+C) = (A+B)+C (c) (ab)A = a(bA) (d) (a+b)A = aA+bA (e) (a−b)A = aA−bA (f) a(A+B) = aA+aB (g) a(A−B) = aA−aB <sub>〔Ch3-1 p.17〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 덧셈과 scalar 곱은 숫자와 같은 규칙입니다.

</details>

### Thm 3.2.2

(a) A(BC) = (AB)C (b) A(B+C) = AB+AC (c) (B+C)A = BA+CA (d) A(B−C) = AB−AC (e) (B−C)A = BA−CA (f) a(BC) = (aB)C = B(aC). 곱셈의 교환법칙은 성립하지 않습니다. <sub>〔Ch3-1 p.18〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 곱셈은 묶는 위치를 바꿀 수 있고 분배되지만 순서는 바꿀 수 없습니다.

**왜 쓰나** 행렬식 정리의 근거입니다.

**함정** A(B+C)와 (B+C)A는 왼쪽·오른쪽을 구분합니다.

</details>

### Thm 3.2.3 Zero matrix

(a) A+0 = 0+A = A (b) A−0 = A (c) A−A = 0 (d) 0A = 0 (e) cA = 0이면 c = 0 또는 A = 0 <sub>〔Ch3-1 p.19〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 영행렬은 숫자 0처럼 동작합니다.

**함정** AB = 0에서 A = 0 또는 B = 0은 나오지 않습니다. (e)는 scalar c일 때만입니다.

</details>

### Identity

AI<sub>n</sub> = A, I<sub>m</sub>A = A (A가 m×n) <sub>〔Ch3-1 p.20〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** I는 숫자 1처럼 곱해도 그대로입니다.

**함정** A가 m×n이면 왼쪽 I와 오른쪽 I의 크기가 다릅니다.

</details>

### Def 3.2.5 Inverse

AB = BA = I이면 A는 invertible, B는 inverse. 없으면 singular. 예: A = \[2 −5; −1 3\], B = \[3 5; 1 2\] <sub>〔Ch3-1 p.21〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** A가 한 일을 되돌리는 행렬입니다.

**왜 쓰나** Ax = b를 x = A⁻¹b로 풉니다.

**작은 예** \[2 −5; −1 3\]\[3 5; 1 2\] = I

**함정** 정방행렬에서만 정의됩니다. 0이 아닌 행렬도 역행렬이 없을 수 있습니다.

</details>

### Thm 3.2.6

역행렬은 유일합니다. B = BI = B(AC) = (BA)C = IC = C <sub>〔Ch3-1 p.22〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 역행렬은 하나뿐입니다.

**왜 쓰나** 그래서 A⁻¹이라는 기호를 쓸 수 있습니다.

</details>

### Thm 3.2.7

\[a b; c d\]는 ad − bc ≠ 0일 때만 invertible이고 A⁻¹ = (1/(ad−bc))\[d −b; −c a\]. ad−bc가 det(A)입니다. <sub>〔Ch3-1 p.23〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 2×2 역행렬은 대각을 맞바꾸고 비대각 부호를 바꾼 뒤 ad − bc로 나눕니다.

**왜 쓰나** ad − bc는 넓이 배율이고 0이면 되돌릴 수 없습니다.

**작은 예** \[2 1; 1 1\]⁻¹ = \[1 −1; −1 2\]

**함정** 3×3에는 이 공식을 쓸 수 없습니다.

</details>

### Thm 3.2.8

(AB)⁻¹ = B⁻¹A⁻¹. 곱의 역은 역의 곱을 역순으로. <sub>〔Ch3-1 p.24〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 마지막에 한 일부터 되돌려야 합니다.

**왜 쓰나** 양말과 신발의 순서와 같습니다.

**함정** (AB)⁻¹ = A⁻¹B⁻¹는 일반적으로 거짓입니다.

</details>

### Powers

A⁰ = I, Aⁿ = A⋯A, A⁻ⁿ = (A⁻¹)ⁿ. A<sup>r</sup>A<sup>s</sup> = A<sup>r+s</sup>, (A<sup>r</sup>)<sup>s</sup> = A<sup>rs</sup> <sub>〔Ch3-1 p.25〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 같은 행렬을 반복 곱합니다.

**왜 쓰나** 지수법칙은 같은 A의 거듭제곱에서 성립합니다.

**함정** (AB)² = A²B²는 AB = BA일 때만입니다.

</details>

### Thm 3.2.9

(a) (A⁻¹)⁻¹ = A (b) (Aⁿ)⁻¹ = A⁻ⁿ = (A⁻¹)ⁿ (c) k ≠ 0이면 (kA)⁻¹ = k⁻¹A⁻¹ <sub>〔Ch3-1 p.25〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 역의 역은 원래 행렬이고, k배의 역은 역의 1/k배입니다.

**작은 예** (2A)⁻¹ = ½A⁻¹

**함정** (kA)⁻¹ = kA⁻¹가 아닙니다.

</details>

### Matrix polynomial

p(A) = a₀I + a₁A + ⋯ + a<sub>m</sub>A<sup>m</sup>. p(x) = x²−2x−3, A = \[−1 2; 0 3\]이면 p(A) = 0 <sub>〔Ch3-1 p.26〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 다항식의 x에 행렬을 넣습니다.

**왜 쓰나** Nilpotent의 (I − A)⁻¹ 계산에 이어집니다.

**함정** 상수항은 a₀가 아니라 a₀I입니다.

</details>

### Thm 3.2.10 Transpose

(a) (Aᵀ)ᵀ = A (b) (A+B)ᵀ = Aᵀ+Bᵀ (c) (A−B)ᵀ = Aᵀ−Bᵀ (d) (kA)ᵀ = kAᵀ (e) (AB)ᵀ = BᵀAᵀ, 역순 <sub>〔Ch3-1 p.27〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 전치도 곱의 순서를 뒤집습니다.

**왜 쓰나** AAᵀ가 대칭임을 한 줄로 증명합니다.

**함정** (AB)ᵀ = AᵀBᵀ는 거짓입니다.

</details>

### Thm 3.2.11

(Aᵀ)⁻¹ = (A⁻¹)ᵀ <sub>〔Ch3-1 p.28〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 전치와 역행렬은 순서를 바꿔도 결과가 같습니다.

**왜 쓰나** A가 가역이면 Aᵀ도 가역입니다. 직교행렬 증명에 쓰입니다.

</details>

### Thm 3.2.12 Trace

(a) tr(Aᵀ) = tr(A) (b) tr(cA) = c tr(A) (c) tr(A+B) = tr A + tr B (d) tr(A−B) = tr A − tr B (e) tr(AB) = tr(BA). tr(AB) ≠ tr(A)tr(B)입니다. <sub>〔Ch3-1 p.29〕</sub> → HW3-1 Q1

<details>
<summary>💡 설명</summary>

**뜻** Trace는 덧셈과 scalar 곱을 통과하고 곱의 순서에 무관합니다.

**왜 쓰나** HW3-1 Q1의 함정입니다.

**함정** tr(AB) = tr(A)tr(B)는 거짓입니다. I₂에서 2 ≠ 4입니다.

</details>

## 성립 vs 불성립

> [!NOTE]
> **성립**
> - A + B = B + A, 덧셈 결합
> - A(BC) = (AB)C
> - A(B+C) = AB + AC, (B+C)A = BA + CA
> - a(BC) = (aB)C = B(aC)
> - AIₙ = A, IₘA = A
> - tr(AB) = tr(BA)
> - cA = 0 ⇒ c = 0 또는 A = 0

> [!CAUTION]
> **일반적으로 불성립**
> - AB = BA
> - (AB)² = A²B²
> - tr(AB) = tr(A)tr(B)
> - A, B 가역 ⇒ A + B 가역
> - AX = C ⇒ X = CA⁻¹
> - `보완` AB = AC ⇒ B = C (A가 가역이면 성립)
> - `보완` AB = 0 ⇒ A = 0 또는 B = 0 (예: \[0 1; 0 0\]² = 0)

소거법칙과 영인자 불성립은 슬라이드 밖 표준 내용입니다. <sub>〔Ch3-1 Atlas〕</sub>
