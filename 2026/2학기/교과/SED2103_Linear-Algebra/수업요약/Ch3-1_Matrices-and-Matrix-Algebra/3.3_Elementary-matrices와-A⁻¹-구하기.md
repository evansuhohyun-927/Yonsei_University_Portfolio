# 3.3 Elementary matrices와 A⁻¹ 구하기

<summary>🟨 기초 Box — 처음 보는 용어 풀이</summary>

- **Elementary row operation** — 두 row 교환, 한 row에 0 아닌 수 곱, 한 row의 배수를 다른 row에 더함. 해를 바꾸지 않습니다.
- **Equivalent** — 하나가 참이면 전부 참. (a) ⇒ (b) ⇒ (c) ⇒ (a)로 원을 돌면 증명됩니다.
- **왜 오른쪽에 A⁻¹이 생기나** — 행 연산 전체를 E로 묶으면 EA = I이므로 E = A⁻¹. 오른쪽에는 EI = E가 남습니다.
- **Consistent** — 해가 적어도 하나 있음. 행 축소에서 0 = c ≠ 0이 나오면 inconsistent

</details>

### Elementary matrix

I에 row operation 한 번을 적용한 행렬입니다. <sub>〔Ch3-1 p.31〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 행 연산 한 번을 행렬로 저장한 것입니다.

**왜 쓰나** 행 연산을 곱셈으로 다룰 수 있어 LU와 역행렬이 설명됩니다.

**함정** 두 번의 연산을 합친 행렬은 elementary가 아닙니다.

</details>

### Thm 3.3.1

E를 왼쪽에 곱하는 것(EA)은 같은 row operation을 A에 적용하는 것과 같습니다. <sub>〔Ch3-1 p.32〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 행 연산은 왼쪽 곱입니다.

**왜 쓰나** 연산을 누적하면 B = Eₖ⋯E₁가 됩니다.

**함정** 오른쪽 곱 AE는 열 연산입니다.

</details>

### Example 1

A의 1행 ×4를 3행에 더하는 E = \[1 0 0; 0 1 0; 4 0 1\], EA의 3행 = \[5 4 12 12\] <sub>〔Ch3-1 p.33〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** E를 곱한 결과와 직접 행 연산한 결과가 같습니다.

**왜 쓰나** [Thm 3.3.1](#thm-331)의 확인입니다.

</details>

### Thm 3.3.2

elementary matrix는 invertible이고 역도 elementary입니다. 행 i ×c ↔ ×1/c, 교환 ↔ 교환, c배 더하기 ↔ −c배 더하기. <sub>〔Ch3-1 p.34–35〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 행 연산은 모두 되돌릴 수 있으므로 E도 가역입니다.

**왜 쓰나** A = E₁⁻¹⋯Eₖ⁻¹의 근거입니다.

**작은 예** r₃ + 4r₁의 역은 r₃ − 4r₁

**함정** 역연산의 부호와 1/c를 확인합니다.

</details>

### Thm 3.3.3

(a) RREF가 I<sub>n</sub> (b) elementary의 곱으로 표현 (c) invertible은 동치입니다. <sub>〔Ch3-1 p.36〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** RREF가 I가 되는 것, E들의 곱인 것, 가역인 것은 같은 말입니다.

**왜 쓰나** 3×3 가역 판정을 행 축소로 합니다.

**함정** 정방행렬 전용입니다.

</details>

### Row equivalence, Thm 3.3.4

E<sub>k</sub>⋯E₁A = B이면 row equivalent. 정방행렬에서 (a) row equivalent (b) B = EA인 invertible E 존재 (c) A = FB인 invertible F 존재는 동치입니다. <sub>〔Ch3-1 p.37〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 행 연산으로 서로 바꿀 수 있는 관계입니다.

**왜 쓰나** Midterm Q1-4의 근거입니다.

</details>

### Inverse algorithm

\[A I\] → \[I A⁻¹\]. 왼쪽에 영행이 나오면 invertible이 아닙니다. <sub>〔Ch3-1 p.38–39〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** A를 I로 만드는 연산을 I에도 똑같이 적용합니다.

**왜 쓰나** EA = I이면 E = A⁻¹이고, 오른쪽에 EI = E가 남습니다.

**함정** 왼쪽에 zero row가 생기면 멈춥니다.

</details>

### Thm 3.3.5

A가 invertible이면 Ax = b의 해는 유일하고 x = A⁻¹b입니다. Ex 5의 해는 (1, −1, 2). <sub>〔Ch3-1 p.40–41〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 가역이면 해가 하나로 정해집니다.

**왜 쓰나** 계수행렬이 같고 b만 바뀌는 문제에 유리합니다.

**함정** A⁻¹는 b의 왼쪽에 곱합니다.

</details>

### Thm 3.3.6

Ax = 0이 trivial solution만 가짐 ⇔ A invertible <sub>〔Ch3-1 p.42〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** Ax = 0의 해가 0뿐이면 A는 정보를 잃지 않습니다.

**왜 쓰나** 가역 판정을 해의 문제로 바꿉니다.

</details>

### Thm 3.3.8

(a) 정방행렬에서 AB = I 또는 BA = I이면 둘 다 invertible이고 서로 역. (b) AB가 invertible이면 A, B 모두 invertible. <sub>〔Ch3-1 p.43〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 정방행렬은 한쪽 곱만 확인해도 됩니다.

**왜 쓰나** 증명에서 계산을 절반으로 줄입니다.

**함정** 정방행렬이 아니면 AB = I여도 BA = I가 아닐 수 있습니다.

</details>

### Consistency

A가 invertible이면 모든 b에 consistent. 아니면 일부 b에만 consistent. b = 0(또는 b = Ax)이면 항상 consistent이므로 consistent한 b는 항상 존재합니다. Ex 8의 조건은 b₁ + b₂ − b₃ = 0. <sub>〔Ch3-1 p.45–46〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 가역이 아니면 만들 수 있는 b가 제한됩니다.

**왜 쓰나** Example 8과 HW3-1 Q7의 유형입니다.

**작은 예** b₃ = b₁ + b₂일 때만 consistent

**함정** b = 0은 항상 해가 있습니다.

</details>
