# 3.1 Operations on matrices

<summary>🟨 기초 Box — 처음 보는 용어 풀이</summary>

- **Scalar · Vector · Matrix** — 숫자 하나 · 숫자를 한 줄로 나열 · 가로세로 직사각형 표
- **Main diagonal** — 왼쪽 위에서 오른쪽 아래로 이어지는 a₁₁, …, aₙₙ. n×n이면 order n
- **Linear combination** — 벡터에 각각 숫자를 곱해 더한 것. 2(1,0) + 3(0,1) = (2,3). Ax는 A의 column을 x만큼 섞은 결과입니다.
- **Dot product 복습** — (1,2,4)·(4,0,2) = 12. AB의 (i,j) 칸은 A의 i행과 B의 j열의 dot product입니다.
- **Transpose** — 1행이 1열이 됩니다. m×n은 n×m이 되고, 정사각이면 main diagonal이 거울입니다.
- **Trace** — main diagonal만 더합니다. 정사각이 아니면 정의되지 않습니다.

</details>

### 표기

m×n 행렬 A = \[a<sub>ij</sub>\], (A)<sub>ij</sub> = a<sub>ij</sub>. n×n은 square matrix of order n, a₁₁,…,a<sub>nn</sub>이 main diagonal입니다. <sub>〔Ch3-1 p.2〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 행 번호가 먼저, 열 번호가 나중입니다.

**왜 쓰나** 모든 행렬 식의 공통 표기입니다.

**작은 예** a₂₃은 2행 3열

**함정** 2×3은 행 2개, 열 3개입니다.

</details>

### Def 3.1.1–3.1.3

크기가 같고 대응 성분이 같으면 equal. A ± B는 성분별. cA는 모든 성분에 c. <sub>〔Ch3-1 p.3–4〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 같은 크기끼리 칸별로 비교하고 더합니다.

**함정** 크기가 다르면 더할 수 없습니다.

</details>

### Row / column vector

한 행이면 row vector, 한 열이면 column vector. 행렬은 열벡터들 또는 행벡터들로 나눌 수 있습니다. <sub>〔Ch3-1 p.5〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 행렬을 세로 벡터들 또는 가로 벡터들의 묶음으로 봅니다.

**왜 쓰나** 같은 행렬을 두 방식으로 보는 것이 Ax와 AB 해석의 핵심입니다.

</details>

### Def 3.1.4 Ax

Ax = x₁a₁ + x₂a₂ + ⋯ + x<sub>n</sub>a<sub>n</sub>. A의 열벡터를 x의 성분으로 묶은 linear combination입니다. <sub>〔Ch3-1 p.6〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** A의 열을 재료로, x를 분량으로 섞은 결과입니다.

**왜 쓰나** Ch3 이후 거의 모든 정리가 이 해석을 씁니다. Ax = b는 b를 열로 만들 수 있는가라는 질문입니다.

**작은 예** \[1 2; 3 4\](1,1) = 1(1,3) + 1(2,4) = (3,7)

**함정** x의 길이는 A의 열 수와 같아야 합니다.

</details>

### Thm 3.1.5 Linearity

A(cu) = c(Au), A(u+v) = Au + Av <sub>〔Ch3-1 p.7〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** A는 덧셈과 scalar 곱을 그대로 통과시킵니다.

**왜 쓰나** Ch6의 선형변환 정의가 바로 이 성질입니다.

</details>

### Def 3.1.6 AB

AB = \[Ab₁ Ab₂ ⋯ Ab<sub>n</sub>\]. A의 열 수 = B의 행 수일 때 정의되며, 안쪽 크기가 맞아야 하고 바깥 크기가 결과 크기입니다: (m×s)(s×n) = m×n. <sub>〔Ch3-1 p.8〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** B의 각 열에 A를 곱해 나란히 세운 것입니다.

**왜 쓰나** 행렬 곱은 변환을 차례로 적용하는 연산입니다.

**작은 예** (2×3)(3×4) = 2×4

**함정** BA는 정의되지 않을 수 있습니다.

</details>

### Thm 3.1.7 Row–column rule

(AB)<sub>ij</sub> = a<sub>i1</sub>b<sub>1j</sub> + ⋯ + a<sub>is</sub>b<sub>sj</sub> <sub>〔Ch3-1 p.10〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** AB의 칸 하나는 A의 행과 B의 열의 내적입니다.

**왜 쓰나** 손계산에서 가장 많이 쓰는 방법입니다.

**작은 예** \[1 2\]\[5;7\] = 5 + 14 = 19

</details>

### Thm 3.1.8

(a) AB의 j열 = A의 열들을 B의 j열 계수로 묶은 linear combination. (b) AB의 i행 = B의 행들을 A의 i행 계수로 묶은 linear combination. <sub>〔Ch3-1 p.12〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** AB의 열은 A의 열의 결합이고, 행은 B의 행의 결합입니다.

**왜 쓰나** B에 zero column이 있으면 AB에도 생기는 이유입니다.

</details>

### Def 3.1.9 Transpose

(Aᵀ)<sub>ij</sub> = (A)<sub>ji</sub>. main diagonal은 그대로입니다. <sub>〔Ch3-1 p.13〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 주대각선을 거울로 행과 열을 바꿉니다.

**왜 쓰나** 대칭행렬, 내적 uᵀv, 직교행렬에 쓰입니다.

**작은 예** \[1 2 3; 4 5 6\]ᵀ = \[1 4; 2 5; 3 6\]

**함정** m×n은 n×m이 됩니다.

</details>

### Def 3.1.10 Trace

tr(A) = 주대각 성분의 합 (square 전용) <sub>〔Ch3-1 p.14〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 주대각선 숫자의 합입니다.

**왜 쓰나** Eigenvalue의 합과 같습니다 ([Thm 4.4.12](../Ch4_Determinants-and-Eigenvalues/4.4_Eigenvalues와-eigenvectors.md#thm-4412)).

**작은 예** tr(\[1 2; 3 4\]) = 5

**함정** 정방행렬에서만 정의됩니다.

</details>

### Def 3.1.11

uᵀv는 matrix inner product(스칼라), uvᵀ는 matrix outer product(행렬). 예: u = (−1,3), v = (2,5) → uᵀv = 13, uvᵀ = \[−2 −5; 6 15\] <sub>〔Ch3-1 p.15〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 열벡터를 눕혀 앞에 곱하면 숫자, 뒤에 곱하면 행렬입니다.

**왜 쓰나** MATLAB의 내적과 외적 곱을 구분할 때 필요합니다.

**함정** uᵀv = (1×n)(n×1) = 1×1, uvᵀ = n×n

</details>
