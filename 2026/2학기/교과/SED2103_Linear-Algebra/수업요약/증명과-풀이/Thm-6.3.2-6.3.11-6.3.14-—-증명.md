# Thm 6.3.2, 6.3.11, 6.3.14 — 증명

> 본문: [6.3 Kernel and range](../Ch6_Linear-Transformations/6.3_Kernel-and-range.md)

**6.3.2** u, v ∈ ker(T)이면 T(cu) = cT(u) = c0 = 0, T(u + v) = T(u) + T(v) = 0. 0 ∈ ker(T)이므로 subspace입니다.

**6.3.11** (a)⇒(b) T(0) = 0이고 one-to-one이므로 T(x) = 0인 x는 0뿐. (b)⇒(a) T(x₁) = T(x₂)이면 T(x₁ − x₂) = 0 → x₁ − x₂ ∈ ker = {0} → x₁ = x₂.

**6.3.14** T = T<sub>A</sub>, A n×n. One-to-one ⇔ Ax = 0 trivial only (6.3.12) ⇔ A invertible (Thm 3.3.9) ⇔ 모든 b에 Ax = b consistent ⇔ onto (6.3.13). `보완`
