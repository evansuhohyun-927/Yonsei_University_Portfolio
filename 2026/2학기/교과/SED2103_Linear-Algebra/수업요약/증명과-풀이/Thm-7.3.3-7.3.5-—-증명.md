# Thm 7.3.3, 7.3.5 — 증명

> 본문: [7.3 The fundamental spaces of a matrix](../Ch7_Dimension-and-Structure/7.3_The-fundamental-spaces-of-a-matrix.md)

**7.3.3** 0·s = 0이므로 0 ∈ S⊥. u, v ∈ S⊥이면 모든 s ∈ S에 (u + v)·s = 0, (cu)·s = 0. `보완`

**7.3.5** Ax = 0 ⇔ 각 행 rᵢ에 rᵢ·x = 0 ⇔ x가 모든 행과 직교 ⇔ x ∈ {행}⊥ = row(A)⊥. 따라서 null(A) = row(A)⊥이고, 차원 계산으로 row(A) = null(A)⊥도 나옵니다. `보완`
