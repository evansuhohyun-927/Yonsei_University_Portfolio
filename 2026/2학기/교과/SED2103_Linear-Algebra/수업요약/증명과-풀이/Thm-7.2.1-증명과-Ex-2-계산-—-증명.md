# Thm 7.2.1 증명과 Ex 2 계산 — 증명

> 본문: [7.2 Properties of bases](../Ch7_Dimension-and-Structure/7.2_Properties-of-bases.md)

**7.2.1** v = c₁v₁ + ⋯ + c<sub>k</sub>v<sub>k</sub> = d₁v₁ + ⋯ + d<sub>k</sub>v<sub>k</sub>이면 (c₁ − d₁)v₁ + ⋯ + (c<sub>k</sub> − d<sub>k</sub>)v<sub>k</sub> = 0. independent이므로 cᵢ = dᵢ. `보완`

**Ex 2** \[v₁ v₂ v₃\]c = (4, 9, 8)을 풀면 c = (29/10, −7/10, 9/5). 검산: 2.9 − 0.7 + 1.8 = 4, 5.8 + 1.4 + 1.8 = 9, 2.9 − 2.1 + 7.2 = 8. `보완`
