# Thm 7.7.4, 7.7.5, 7.7.7 이유 — 증명

> 본문: [7.7 The projection theorem](../Ch7_Dimension-and-Structure/7.7_The-projection-theorem.md)

**7.7.4** W의 basis를 열로 한 M에서 x₁ = Mc라 두면 x − Mc ∈ W⊥ ⇔ Mᵀ(x − Mc) = 0 ⇔ MᵀMc = Mᵀx. MᵀM이 invertible이므로 c가 하나로 정해집니다. `보완`

**7.7.5** 위의 c = (MᵀM)⁻¹Mᵀx를 x₁ = Mc에 넣으면 P = M(MᵀM)⁻¹Mᵀ. <sub>〔Ch7-2 p.9〕</sub>

**7.7.7** 해 x를 x = x<sub>r</sub> + x<sub>n</sub>(row(A) ⊕ null(A))로 나누면 Ax<sub>r</sub> = Ax = b. 다른 해는 x<sub>r</sub> + (null 원소)이고 두 성분이 직교하므로 ‖x‖² = ‖x<sub>r</sub>‖² + ‖x<sub>n</sub>‖² ≥ ‖x<sub>r</sub>‖². `보완`
