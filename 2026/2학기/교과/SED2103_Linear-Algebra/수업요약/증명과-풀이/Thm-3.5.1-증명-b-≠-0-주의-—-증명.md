# Thm 3.5.1 증명, b ≠ 0 주의 — 증명

> 본문: [3.5 Geometry of linear systems](../Ch3-2_Subspaces-Geometry-LU/3.5_Geometry-of-linear-systems.md)

(⇒) A(x₀ + w) = b + 0 = b. (⇐) x가 해이면 w = x − x₀에서 Aw = b − b = 0이므로 x = x₀ + w. <sub>〔Ch3-2 p.25〕</sub>

`보완` [Thm 3.5.6](../Ch3-2_Subspaces-Geometry-LU/3.5_Geometry-of-linear-systems.md#thm-356)은 Ax = 0에만 해당합니다. b ≠ 0이면 aᵢ·x = bᵢ ≠ 0이라 row vector에 직교하지 않습니다. `정정` 번호가 3.5.3 다음 3.5.5로 건너뜁니다. <sub>〔Ch3-2 Atlas〕</sub>
