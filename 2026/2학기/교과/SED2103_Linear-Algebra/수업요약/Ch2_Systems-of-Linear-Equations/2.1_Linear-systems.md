# 2.1 Linear systems

> **Ch2 · Systems of Linear Equations** · 슬라이드 p.2–7  
> **선수 개념** [1.1 벡터 연산과 Rⁿ](../Ch1_Vectors/1.1_벡터-연산과-Rⁿ.md)  
> **이어지는 곳** [2.2 Row reduction](2.2_Row-reduction.md)

**이 절의 정의·정리** [Thm 2.1.1](#thm-211)

a₁x₁ + ⋯ + a<sub>n</sub>x<sub>n</sub> = b가 linear equation이고, b = 0이면 homogeneous입니다. m개 식, n개 미지수의 일반형은 a<sub>i1</sub>x₁ + ⋯ + a<sub>in</sub>x<sub>n</sub> = b<sub>i</sub>입니다. <sub>〔Ch2 p.2〕</sub>

### Consistent / inconsistent

해가 하나 이상이면 consistent, 없으면 inconsistent입니다. <sub>〔Ch2 p.5〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 해가 있느냐 없느냐의 구분입니다.

**왜 쓰나** Column space와 연결됩니다.

**함정** Consistent는 해가 1개라는 뜻이 아닙니다.

</details>

### Thm 2.1.1

모든 linear system의 해는 0개, 1개, 무한개 중 하나입니다. <sub>〔Ch2 p.5〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 해가 2개 이상이면 두 해를 잇는 직선 위가 모두 해가 되므로 무한합니다.

**왜 쓰나** T/F 문제의 근거입니다.

**작은 예** x + y = 1은 무한, x + y = 1과 x + y = 2를 함께 놓으면 0개

**함정** 선형 시스템에만 해당합니다. Midterm Q10처럼 비선형이면 18개도 가능합니다.

</details>

### Example 2·3

x − y = 1, 2x + y = 6 → 슬라이드 풀이 없음. x + y = 4, 3x + 3y = 6은 평행선으로 해가 없습니다. <sub>〔Ch2 p.5〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 두 직선의 교점이 해입니다.

**왜 쓰나** 해의 개수를 기하로 보는 첫 예입니다.

**작은 예** x − y = 1, 2x + y = 6 → x = 7/3, y = 4/3

</details>

### Augmented matrix

계수와 상수항만 모은 직사각 배열입니다. <sub>〔Ch2 p.6〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 변수 이름을 지우고 숫자만 남긴 표입니다.

**왜 쓰나** 행 연산과 MATLAB 계산의 출발점입니다.

**작은 예** x + y = 2 → \[1 1 | 2\]

**함정** 변수 순서를 고정해야 합니다. 없는 변수의 계수는 0으로 적습니다.

</details>

### Elementary row operations

① 행에 0 아닌 상수 곱하기 ② 두 행 교환 ③ 한 행의 상수배를 다른 행에 더하기. 해 집합을 바꾸지 않습니다. <sub>〔Ch2 p.7〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 식의 순서 바꾸기, 양변에 같은 수 곱하기, 식끼리 더하기와 같습니다.

**왜 쓰나** 되돌릴 수 있어서 해 집합이 변하지 않습니다. Ch3에서 elementary matrix가 됩니다.

**함정** 0을 곱하면 안 됩니다. 식 하나가 사라집니다.

</details>
