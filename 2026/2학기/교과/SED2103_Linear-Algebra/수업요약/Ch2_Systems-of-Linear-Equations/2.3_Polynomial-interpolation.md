# 2.3 Polynomial interpolation

> **Ch2 · Systems of Linear Equations** · 슬라이드 p.30–33  
> **선수 개념** [2.2 Row reduction](2.2_Row-reduction.md)  
> **이어지는 곳** —

**이 절의 정의·정리** [Thm 2.3.1](#thm-231)

n개의 점을 지나는 다항식 p(x) = a₀ + a₁x + ⋯ + a<sub>n−1</sub>x<sup>n−1</sup>의 계수는 linear system의 해입니다. 계수행렬의 각 행은 1, x<sub>i</sub>, x<sub>i</sub>², …입니다. <sub>〔Ch2 p.30–31〕</sub>

### Thm 2.3.1

x좌표가 서로 다른 n개의 점을 지나는, 차수 n−1 이하의 다항식은 유일합니다. <sub>〔Ch2 p.31〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 서로 다른 점 n개는 n−1차 이하 다항식 하나를 정합니다.

**왜 쓰나** Vandermonde 계수행렬이 가역이기 때문입니다.

**작은 예** 점 2개 → 직선 1개

**함정** x좌표가 같은 두 점이 있으면 보장되지 않습니다.

</details>

### Example 7

(1,3), (2,−2), (3,−5), (4,0) → p(x) = 4 + 3x − 5x² + x³ <sub>〔Ch2 p.32–33〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 계수를 미지수로 두면 곡선 문제가 선형 시스템이 됩니다.

**왜 쓰나** Midterm Q5, Q12, Q14의 방식입니다.

**작은 예** p(2) = 4 + 6 − 20 + 8 = −2

</details>

시험 응용: Midterm(Q5, Q12, Q14)과 HW2(Q6–7)에 보간 문제가 출제되었습니다.

## 혼동하기 쉬운 개념 (Ch1–2)

| A | B | 핵심 차이 |
|---|---|---|
| point | vector | point는 위치, vector는 변화량 |
| kv | u·v | kv는 vector, u·v는 scalar |
| orthogonal | orthonormal | orthonormal = orthogonal + 각 norm 1 |
| direction vector | normal vector | 도형을 따라감 vs 평면에 수직 |
| REF | RREF | RREF는 leading 1 열의 위아래가 모두 0이고 유일 |
| Gaussian | Gauss–Jordan | REF + back substitution vs RREF까지 |
| leading variable | free variable | 식으로 결정됨 vs parameter로 선택 |
| homogeneous | nonhomogeneous | b = 0이면 trivial 해가 항상 존재 |

> [!NOTE]
> **맞는 진술**
> - norm은 항상 0 이상
> - 행 연산은 row에만 (열 교환은 변수 순서를 바꿈)
> - homogeneous system은 항상 consistent
> - 식 > 미지수여도 consistent일 수 있음 (Midterm Q3)

> [!CAUTION]
> **흔한 오개념**
> - 평행하고 길이 같으면 같은 벡터 → 방향이 반대면 다름
> - 행에 0을 곱해도 됨 → 해집합이 바뀜
> - 미지수 > 식이면 항상 무한해 → nonhomogeneous는 inconsistent 가능
> - REF도 하나로 정해짐 → RREF만 유일

| 시험 체크리스트 | 순서 |
|---|---|
| 벡터 계산 | 차원 확인 → 성분별 연산 → 끝점 − 시작점 → 제곱·합·제곱근 → 직교는 내적 0 |
| 직선·평면 | x₀와 v 확보 → x = x₀ + tv / x₀와 n 확보 → n·(x − x₀) = 0 |
| 선형 시스템 | 변수 순서 고정 → augmented matrix → 한 번에 한 연산 → 모순 행 → free variable → 대입 검산 |
