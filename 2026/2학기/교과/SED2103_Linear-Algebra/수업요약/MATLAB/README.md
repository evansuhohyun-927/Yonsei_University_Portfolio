# MATLAB 실습 — 주차별 명령·코드

MATLAB 세션(Week 1–8) 내용을 주차별로 정리했습니다. 각 노트는 개념 요약 → 명령 표 → 코드 → 세션 시간표 순서입니다.

비대면 세션은 대부분 MATLAB 실습입니다. 각 장 끝의 MATLAB 상자는 이론과 연결된 부분만 보여 주고, 이 장은 세션을 주차 순서로 모읍니다. 주차마다 명령 표, 대표 코드, 조작 도구, 강의 영상과 시간표, 해당 퀴즈가 있습니다. <sub>〔Week 1–9 transcript〕</sub> <sub>〔W10 docx·프레임〕</sub>
