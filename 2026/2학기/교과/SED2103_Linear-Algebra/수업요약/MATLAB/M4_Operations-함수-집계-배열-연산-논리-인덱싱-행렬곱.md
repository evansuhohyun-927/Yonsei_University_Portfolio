# M4 Operations: 함수, 집계, 배열 연산, 논리 인덱싱, 행렬곱

함수는 성분마다 적용되고, 집계 함수는 열별로 작동합니다. 점(.)이 붙으면 성분별, 없으면 선형대수 연산입니다. <sub>〔W4〕</sub> <sub>〔33:50〕</sub>

| 명령 | 하는 일 | 예 → 결과 | 함정 |
|---|---|---|---|
| `abs(v)` 등 | 성분마다 적용 | `sign([-2 0 3])` → \[−1 0 1\] |   |
| `min max sum prod` | 벡터 전체, 행렬은 열별 | `max([3 8 1; 6 2 9])` → \[6 8 9\] | 전체 최댓값 `max(max(m))`, 행별 `max(m')` |
| `diff` | 인접 차이, 길이 1 감소 | `diff([2 5 11 4])` → \[3 6 −7\] |   |
| `.* ./ .^` | 같은 크기 성분별 연산 | `(2:5).*[1 0 2 3]` → \[2 0 8 15\] | 크기가 다르면 오류(스칼라 제외) |
| `* / \ ^` | 행렬 연산 | `A*B`: 2×3 · 3×4 = 2×4 | `A^2` = A\*A, `A.^2`는 성분 제곱 |
| `A - 3` | 스칼라 확장 | 모든 성분에서 3을 뺌 | 수학적으로는 정의되지 않지만 MATLAB은 받아 줍니다. |
| `v > 5` | logical vector | `[7 2 9]>5` → \[1 0 1\] | `sum(v>5)` = 개수 |
| `v(v>5)` | logical indexing: 값 추출 | `[7 2 9 4 10]` → \[7 9 10\] |   |
| `find` | 조건을 만족하는 위치 | `find([7 2 9 4 10]>5)` → \[1 3 5\] | 행렬이면 linear index, 없으면 빈 벡터 |
| `all any isequal` | 모두 / 하나라도 / 완전 일치 | `isequal([1 2],[1 2])` → 1 | `==`는 성분별 비교 |
| `r*c` / `c*r` | 내적(스칼라) / 외적(행렬) | `[4 5 6]*[1;2;3]` → 32 | 순서가 크기를 정합니다. |
| `dot cross` | 내적 / 3차원 외적 | `cross([1 0 0],[0 1 0])` → \[0 0 1\] | outer product uvᵀ와 cross는 다릅니다. |

```matlab
mat = [3 8 1; 6 2 9];
max(mat)            % [6 8 9] 열별
max(max(mat))       % 9
vec = [7 2 9 4 10];
vec(vec > 5)        % [7 9 10]
find(vec > 5)       % [1 3 5]
vec(vec < 0) = [];  % 음수 제거
[4 5 6]*[1;2;3]     % 32
```
