# M7.2 Population migration

### Migration matrix

열 = 출발 지역, 행 = 도착 지역. 각 열은 그 지역 인구가 1년 뒤 어디에 있는지의 비율이고 열 합은 1입니다. x<sub>k+1</sub> = Mx<sub>k</sub>. <sub>〔W10 06:30–08:30〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 열은 출발 지역, 행은 도착 지역입니다. 각 열은 그 지역 사람이 1년 뒤 어디로 가는지의 비율입니다.

**왜 쓰나** Mx<sub>k</sub>의 각 행이 "남은 사람 + 들어온 사람"이 됩니다.

**작은 예** 5%/3%: M = \[0.95 0.03; 0.05 0.97\]

**함정** 열 합이 1이어야 총인구가 보존됩니다. 행 합은 1이 아닐 수 있습니다.

</details>

### Example (5%·3%)

매년 도시 5% → 교외, 교외 3% → 도시. 2000년 x₀ = (r₀, s₀). x₁ = r₀(0.95, 0.05) + s₀(0.03, 0.97) = Mx₀, M = \[0.95 0.03; 0.05 0.97\] (6) <sub>〔W10 05:15–06:30〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 도시 5%가 교외로, 교외 3%가 도시로 갑니다.

**왜 쓰나** 이주 행렬을 처음 세우는 예입니다.

**작은 예** x₀ = (600, 400) → x₁ = (582, 418)

**함정** 0.03은 1행 2열입니다. 교외(2열)에서 도시(1행)로 간다는 뜻입니다.

</details>

### Practice 1

도시 7% → 교외, 교외 5% → 도시, 2015년 x₀ = (800,000, 500,000). M = \[0.93 0.05; 0.07 0.95\], x₁ = (769,000, 531,000), x₂ = M²x₀ = (741,720, 558,280). <sub>〔W10 21:45–23:00〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 7%/5% 비율과 2015년 인구로 2017년을 추정합니다.

**왜 쓰나** x₂ = M²x₀를 손과 MATLAB으로 확인합니다.

**작은 예** x₁ = (769,000, 531,000), x₂ = (741,720, 558,280)

**함정** 2년 뒤이므로 M을 두 번 곱합니다. 합계 1,300,000은 그대로입니다.

</details>

### Practice 2

2012년 California 38,041,430명, 그 밖 미국 275,872,610명, 유출 748,252명, 유입 493,641명. p<sub>out</sub> = 0.01967, p<sub>in</sub> = 0.00179 (소수 5자리), M = \[0.98033 0.00179; 0.01967 0.99821\]. 2022년 = M¹⁰x₀ ≈ (35,728,987, 278,185,053), 합계 313,914,040 불변. <sub>〔W10 24:30–25:00〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 이동 인원 수를 인구로 나눠 비율을 만든 뒤 10년을 반복합니다.

**왜 쓰나** 실제 데이터로 이주 행렬을 만드는 절차입니다.

**작은 예** p<sub>out</sub> = 748,252 / 38,041,430 ≈ 0.01967

**함정** 나가는 비율은 California 인구로, 들어오는 비율은 California 밖 인구로 나눕니다. 분모를 섞지 않습니다.

</details>

### 열 합 1 ⇒ 총인구 보존

M의 각 열 합이 1이면 sum(Mx) = sum(x)입니다. Practice 1의 확인 질문 `sum(x2)` = 1,300,000이 이 성질입니다. `보완` <sub>〔W10 23:00〕</sub> <sub>〔W10 Models〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 떠난 사람은 다른 지역에 도착하므로 전체 인원이 그대로입니다.

**왜 쓰나** 계산 결과를 검산하는 가장 빠른 방법입니다.

**작은 예** 800,000 + 500,000 = 741,720 + 558,280

**함정** 비율을 반올림하면 끝자리에 반올림 차이가 생길 수 있습니다(Practice 2).

</details>

### Steady state

k가 커지면 xₖ가 Mx = x인 값에 다가갑니다. 5%·3% 예에서 0.05r = 0.03s이므로 r : s = 3 : 5, 총 1000이면 (375, 625). M의 eigenvalue는 1과 0.92입니다. `보완` <sub>〔W10 Atlas〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** k가 커지면 xₖ가 더 변하지 않는 값에 가까워집니다. 나가는 사람 수와 들어오는 사람 수가 같아지는 지점입니다.

**왜 쓰나** 장기 예측입니다. 처음 인구와 무관하게 같은 비율로 갑니다.

**작은 예** 0.05r = 0.03s, r + s = 1000 → (375, 625)

**함정** 이번 슬라이드 범위 밖입니다. Ch4의 eigenvalue 1과 eigenvector로 정식화합니다.

</details>
