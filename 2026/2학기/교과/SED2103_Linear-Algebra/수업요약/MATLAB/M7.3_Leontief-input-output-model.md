# M7.3 Leontief input-output model

### Production vector x

n개 부문이 1년 동안 생산하는 양을 나열한 x ∈ Rⁿ. <sub>〔W10 09:00〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 각 산업이 1년 동안 생산하는 총량입니다.

**왜 쓰나** 구해야 하는 미지수입니다.

**작은 예** x = (x₁, x₂, x₃) = (제조, 농업, 서비스)

**함정** 최종 수요 d보다 항상 크거나 같습니다. 중간 수요가 더해지기 때문입니다.

</details>

### Final demand d

생산하지 않고 소비만 하는 open sector가 각 부문에 요구하는 양. Bill of final demands라고도 합니다. <sub>〔W10 09:00〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 생산은 하지 않고 소비만 하는 open sector가 원하는 양입니다.

**왜 쓰나** 주어지는 값입니다.

**작은 예** d = (50, 30, 20)

</details>

### Unit consumption vector

부문 j가 1단위를 생산할 때 필요한 투입을 나열한 c<sub>j</sub> ∈ Rⁿ. 예: 제조·농업·서비스의 c₁ = (0.5, 0.2, 0.1), c₂ = (0.4, 0.3, 0.1), c₃ = (0.2, 0.1, 0.3). <sub>〔W10 11:00〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 그 산업이 1단위를 만들 때 필요한 각 산업 제품의 양입니다.

**왜 쓰나** C의 열이 됩니다.

**작은 예** c₁ = (0.5, 0.2, 0.1)

**함정** 열로 읽습니다. 행으로 읽으면 "한 제품이 각 산업에 얼마나 쓰이는지"가 됩니다.

</details>

### Example 1 (100 units)

제조업이 100단위를 생산하면 100c₁ = (50, 20, 10)을 주문·소비합니다. <sub>〔W10 12:15〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 제조업 100단위 생산에 드는 재료는 100c₁입니다.

**왜 쓰나** scalar 곱 하나로 중간 수요를 구하는 예입니다.

**작은 예** 100(0.5, 0.2, 0.1) = (50, 20, 10)

**함정** 강의 음성은 c₁을 첫 행(0.5, 0.4, 0.2)으로 읽었습니다. 결과 (50, 20, 10)과 맞는 것은 열입니다.

</details>

### Consumption matrix C

중간 수요 = x₁c₁ + x₂c₂ + x₃c₃ = Cx, C = \[c₁ c₂ c₃\] = \[0.5 0.4 0.2; 0.2 0.3 0.1; 0.1 0.1 0.3\] (12) <sub>〔W10 13:45〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** C = \[c₁ c₂ c₃\]이고 중간 수요는 x₁c₁ + x₂c₂ + x₃c₃ = Cx입니다.

**왜 쓰나** 행렬 × 벡터 = 열의 linear combination([Def 3.1.4](../Ch3-1_Matrices-and-Matrix-Algebra/3.1_Operations-on-matrices.md#def-314-ax))을 그대로 씁니다.

**작은 예** 열 합 0.8, 0.8, 0.6

**함정** C의 (i, j) 성분은 "j 산업 1단위에 드는 i 제품"입니다.

</details>

### Leontief equation

x = Cx + d (13), 생산 = 중간 수요 + 최종 수요. 정리하면 (I − C)x = d (14). <sub>〔W10 13:45–16:00〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 생산량 = 중간 수요 + 최종 수요입니다. x를 모으면 (I − C)x = d입니다.

**왜 쓰나** 경제 문제가 Ax = b 하나로 줄어 rref, 역행렬, backslash로 풉니다.

**작은 예** x − Cx = d → (I − C)x = d

**함정** x를 묶을 때 x = Ix로 써야 합니다. (1 − C)x로 쓰면 크기가 맞지 않습니다.

</details>

### Example 2

C가 (12)이고 d = (50, 30, 20)이면 \[I − C | d\]를 row reduce해 x ≈ (226, 119, 78). 정확히는 (6100/27, 3200/27, 700/9). <sub>〔W10 16:00–17:45〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** Example 1의 C와 d = (50, 30, 20)으로 x를 구합니다.

**왜 쓰나** 손계산과 MATLAB 결과를 맞춰 봅니다.

**작은 예** x = (6100/27, 3200/27, 700/9) ≈ (225.9, 118.5, 77.8)

**함정** 반올림하면 226, 119, 78입니다. d보다 훨씬 큽니다.

</details>

### Theorem (Leontief)

C와 d가 nonnegative이고 C의 각 column sum이 1보다 작으면 (I − C)⁻¹이 존재하고, x = (I − C)⁻¹d (15)는 nonnegative이며 x = Cx + d (16)의 유일한 해입니다. <sub>〔W10 18:00〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** C, d가 음수 없고 C의 각 열 합이 1보다 작으면 (I − C)⁻¹이 있고 x = (I − C)⁻¹d는 음수 없는 유일한 해입니다.

**왜 쓰나** 계산 전에 sum(C)만 보고 해가 있는지 판단합니다.

**작은 예** Example 2 열 합 0.8, 0.8, 0.6 → 해 있음

**함정** 충분조건입니다. 열 합이 1 이상이어도 역행렬이 있을 수는 있지만 정리가 보장하지 않습니다.

</details>

### Column sum &lt; 1

한 부문이 1단위를 생산하는 데 1단위 가치보다 적은 투입이 필요하다는 뜻입니다. 1 이상이면 계수 설정이 틀렸을 가능성이 큽니다. (12)의 열 합은 0.8, 0.8, 0.6입니다. <sub>〔W10 19:30〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 1단위 가치를 만드는 데 드는 재료 가치가 1단위보다 작다는 뜻입니다.

**왜 쓰나** 모형의 숫자가 경제적으로 맞는지 검사합니다.

**작은 예** 열 합 1.05 → 손해 보며 생산하는 셈

**함정** 1 이상이면 계수 설정을 먼저 의심합니다.

</details>

### (I − C)⁻¹ = I + C + C² + ⋯

열 합 &lt; 1이면 Cᵐ → 0이고 x = d + Cd + C²d + ⋯입니다. 최종 수요, 그것을 위한 1차 투입, 다시 그 투입을 위한 2차 투입의 합입니다. (I − C)⁻¹의 열 j는 부문 j의 최종 수요가 1 늘 때 각 부문이 더 생산해야 하는 양(multiplier)입니다. Example 2의 (1,1) 성분 = 80/27 ≈ 2.963. `보완` <sub>〔Lay §2.6〕</sub> <sub>〔W10 Models〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 생산 사슬을 라운드별로 끝없이 더한 것이 역행렬입니다.

**왜 쓰나** 역행렬 성분의 경제적 의미(파급 효과)와 x ≥ 0인 이유를 함께 보여 줍니다.

**작은 예** Example 2: d부터 5라운드(d + ⋯ + C⁵d)까지 더하면 정확한 x 합의 약 80%

**함정** 열 합 &lt; 1일 때만 수렴합니다. 수렴이 느릴 수 있어 계산에는 backslash를 씁니다.

</details>

### Practice 3

C = \[0.2 0.2 0; 0.3 0.1 0.3; 0.1 0 0.2\], d = (40, 60, 80): x = (1/29)(2400, 3800, 3200) ≈ (82.8, 131.0, 110.3). 세 방법 모두 같은 답. <sub>〔W10 28:15–28:45〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 다른 C와 d로 세 가지 풀이를 비교합니다.

**왜 쓰나** 세 방법이 같은 답을 주는지 확인합니다.

**작은 예** x = (2400, 3800, 3200)/29 ≈ (82.8, 131.0, 110.3)

**함정** 열 합은 0.6, 0.3, 0.5입니다.

</details>
