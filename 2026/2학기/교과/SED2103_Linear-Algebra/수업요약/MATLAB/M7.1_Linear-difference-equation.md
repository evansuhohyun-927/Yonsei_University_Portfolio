# M7.1 Linear difference equation

### Dynamical system

시간에 따라 변하는 시스템을 일정 간격으로 측정해 벡터열 x₀, x₁, x₂, …를 얻습니다. x<sub>k</sub>는 k번째 측정 시점의 상태입니다. <sub>〔W10 00:45〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 시간에 따라 상태가 변하는 시스템입니다. 일정 간격마다 측정해 x₀, x₁, x₂, …를 얻습니다.

**왜 쓰나** 연속 변화를 행렬 계산으로 다룰 수 있게 바꿉니다.

**작은 예** x<sub>k</sub> = (k년 도시 인구, k년 교외 인구)

**함정** k는 측정 순번입니다. 1년인지 1초인지는 문제가 정합니다.

</details>

### Linear difference equation

x<sub>k+1</sub> = Ax<sub>k</sub> (k = 0, 1, 2, …). x₀가 주어지면 x₁, x₂, …를 차례로 계산합니다. Recurrence relation이라고도 합니다. <sub>〔W10 00:45, 08:30〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 오늘 상태에 같은 행렬 A를 곱하면 다음 상태가 됩니다.

**왜 쓰나** 미래 상태를 행렬 곱 반복으로 계산합니다. 이주, 인구 구조, 회로 등에 같은 틀을 씁니다.

**작은 예** x₁ = Ax₀, x₂ = Ax₁

**함정** Differential equation(미분방정식)과 다른 개념입니다. 강의 음성의 "differential"은 difference입니다.

</details>

### xₖ = Aᵏx₀

x₂ = A(Ax₀) = A²x₀, 일반적으로 x<sub>k</sub> = Aᵏx₀. A를 k번 곱하는 것과 Aᵏ을 한 번 곱하는 것은 같습니다. <sub>〔W10 25:00〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** A를 k번 곱한 것은 Aᵏ을 한 번 곱한 것과 같습니다.

**왜 쓰나** 몇 년 뒤를 바로 계산합니다. MATLAB에서는 `M^10*x0` 한 줄입니다.

**작은 예** x₃ = A(A(Ax₀)) = A³x₀

**함정** 행렬 곱의 결합법칙([Thm 3.2.2](../Ch3-1_Matrices-and-Matrix-Algebra/3.2_Inverses와-대수-성질.md#thm-322)) 덕분입니다. 순서를 바꾼 x₀A는 크기가 맞지 않습니다.

</details>

| 용어 | 뜻 |
|---|---|
| Linear | 다음 상태가 현재 상태의 행렬 곱으로 정해짐 |
| Difference | 이산 시간 단계 사이의 관계 (미분방정식 differential과 다름) |
| Recurrence relation | 이전 항으로 다음 항을 정하는 점화식 |

<sub>〔W10 Atlas〕</sub>

<details>
<summary>💡 용어 표 설명</summary>

Linear는 다음 상태가 행렬 곱으로 정해진다는 뜻, difference는 이산 단계 사이의 관계라는 뜻입니다. Recurrence relation은 점화식입니다.

</details>
