# M7.4 MATLAB: Week7_practice.m

스크립트를 만들고 실습마다 `%%` 섹션 줄을 넣어 Run Section으로 실행합니다. <sub>〔W10 21:00〕</sub>

```matlab
%% Practice 1: city-suburb migration
M  = [0.93 0.05; 0.07 0.95];      % 열 합 = 1
x0 = [800000; 500000];            % 2015 [city; suburbs], 세로 벡터
x1 = M*x0                         % 2016: 769000 531000
x2 = M*x1                         % 2017: 741720 558280 (= M^2*x0)
sum(x2)                           % 1300000 유지

%% Practice 2: California and the rest of the U.S.
pOut = round(748252/38041430, 5)  % 0.01967
pIn  = round(493641/275872610, 5) % 0.00179
M = [1-pOut pIn; pOut 1-pIn];
x = [38041430; 275872610];        % 2012
for k = 1:10                      % 2013, ..., 2022
    x = M*x;
end
x                                 % = M^10*[38041430; 275872610]

%% Example 2: Leontief, 세 가지 풀이
C = [0.5 0.4 0.2; 0.2 0.3 0.1; 0.1 0.1 0.3];
d = [50; 30; 20];
sum(C)                            % 0.8 0.8 0.6 (all < 1)
x = (eye(3) - C) \ d              % (1) backslash: 225.9 118.5 77.8
x = inv(eye(3) - C) * d           % (2) inverse
R = rref([eye(3) - C, d]); x = R(:,end)   % (3) row reduce

%% Practice 4: U.S. economy 1958 (7 sectors)
% C는 7×7, d = [74000; 56000; 10500; 25000; 17500; 196000; 5000]
x = (eye(7) - C) \ d;  round(x)
```

| 방법 | 코드 | 특징 |
|---|---|---|
| Backslash | `A\b` | 강의 권장. Gaussian elimination 기반으로 빠르고 정확합니다. |
| 역행렬 | `inv(A)*b` | 개념은 쉽지만 역행렬 전체를 구해 큰 행렬에서 매우 느립니다. |
| rref | `rref([A b])` | 손풀이와 같은 과정. 해를 읽는 단계가 번거롭습니다. |

"차원이 커지면 backslash가 사실상 유일한 현실적 방법"이라고 설명합니다. W9의 flop 비교(역행렬 2n³)와 같은 이유입니다. <sub>〔W10 28:45〕</sub> <sub>〔W9 17:32〕</sub>

| 증상 | 원인 | 해결 |
|---|---|---|
| Incorrect dimensions for matrix multiplication | `x0 = [800000 500000]` 가로 벡터 | `;`로 세로 벡터 또는 `'` |
| 값이 비정상적으로 큼 | `M.^10` 원소별 제곱 | `M^10` |
| 엉뚱한 해 | `d/(I-C)` 방향 반대 | `(I-C)\d` |
| 해에 음수 | 열 합 ≥ 1 또는 입력 오타 | `sum(C)` 먼저 확인 |
