# M3 Vectors and Matrices: 만들기, 인덱싱, 모양 바꾸기

벡터와 행렬을 만들고, (행, 열) 또는 단일 인덱스로 꺼내고, 크기와 모양을 바꿉니다. 단일 인덱스는 열 방향입니다. <sub>〔W3〕</sub> <sub>〔30:25〕</sub>

| 명령 | 하는 일 | 예 → 결과 | 함정 |
|---|---|---|---|
| `[1 2 3]` / `[1;2;3]` | 행벡터 / 열벡터 | `[1:3]'` → 열벡터 | `'`는 전치(복소수면 켤레 전치) |
| `first:step:last` | 등간격 벡터 | `3:2:10` → \[3 5 7 9\] | last를 넘지 않습니다. step 기본 1 |
| `linspace(a,b,n)` | 양 끝 포함 n개 | `linspace(0,1,5)` → \[0 .25 .5 .75 1\] | 개수 지정이고 간격은 자동 |
| `logspace(a,b,n)` | 10^a – 10^b 사이 n개 | `logspace(0,2,3)` → \[1 10 100\] |   |
| `v(k)` `v([1 5])` | 인덱싱 (1부터) | `w([5 1 3])` → 5·1·3번째 | 0 인덱스 없음. 범위 밖 대입은 벡터를 늘립니다. |
| `m(i,j)` `m(:,j)` | 행렬 성분 / 열 전체 | `mat(1,:)` = 1행 | `:`는 "전부" |
| `m(k)` | 단일(linear) 인덱스 | `[2 4 6; 1 3 5]`에서 `m(3)` → 4 | 열 순서로 셉니다(column-major). |
| `zeros ones rand randi` | 크기 지정 생성 | `randi([10,30],2,3)` | `zeros(3)`은 3×3 |
| `length size numel` | 가장 긴 차원 / \[행 열\] / 전체 개수 | 3×4 행렬: 4, \[3 4\], 12 | `[r,c] = size(m)` |
| `reshape(m,r,c)` | 열 순서를 유지하며 모양 변경 | 3×4 → `reshape(m,2,6)` | 원소 수가 같아야 합니다. |
| `fliplr flipud` | 좌우 / 상하 뒤집기 | `fliplr([1 2 3])` → \[3 2 1\] |   |
| `repmat(m,a,b)` | 블록 반복 | `repmat([1 2],2,2)` → 2×4 | 큰 행렬은 메모리를 많이 씁니다. |
| `[]` | 빈 벡터·삭제 | `mat(:,2) = []` | 행·열 단위로만 삭제 가능 |

```matlab
v = 3:2:10              % [3 5 7 9]
m = [2 4 6; 1 3 5];
m(3)                    % 4 (열 순서 2,1,4,3,6,5)
m(:,2) = []             % [2 6; 1 5]
mat = [1:3; 44 9 2; 5:-1:3];
mat(:,4) = [8;11;33];   % 열 추가
reshape(mat,2,6)        % 열 순서 유지
```
