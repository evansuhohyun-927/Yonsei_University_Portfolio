> **이어지는 곳** [3.7 LU-decomposition](3.7_LU-decomposition.md)

<details>
<summary>🟨 기초 Box — 처음 보는 용어 풀이</summary>

- **행렬 크기 m×n** — m = 행 수, n = 열 수. m = n이면 square
- **(AB)ᵀ = BᵀAᵀ** — 순서가 뒤집힙니다. 신고 벗는 순서와 같습니다.
- **Aᵏ** — A를 k번 곱한 것. Aᵏ = 0이면 nilpotent

</details>

| 유형 | 정의 | 성질 | 출처 |
|---|---|---|---|
| Diagonal | 주대각 밖이 0 | d<sub>i</sub> ≠ 0이면 D⁻¹ = diag(1/d<sub>i</sub>), Dᵏ = diag(d<sub>i</sub>ᵏ) | <sub>〔Ch3-2 p.36〕</sub> |
| Triangular | 주대각 위 또는 아래가 0 | Thm 3.6.1: 전치는 상↔하, 곱은 같은 형태, invertible ⇔ 대각 ≠ 0, 역도 같은 형태 | <sub>〔Ch3-2 p.37–39〕</sub> |
| Symmetric | Aᵀ = A | Thm 3.6.2: Aᵀ, A±B, kA 대칭. Thm 3.6.3: AB 대칭 ⇔ AB = BA. Thm 3.6.4: A⁻¹ 대칭 | <sub>〔Ch3-2 p.40–42〕</sub> |
| Skew-symmetric | Aᵀ = −A | 주대각이 0 | <sub>〔Ch3-2 p.40〕</sub> |
| AAᵀ, AᵀA | A가 m×n | 크기 m×m, n×n, 항상 대칭. Thm 3.6.5: square A이면 A, AAᵀ, AᵀA는 모두 invertible이거나 모두 singular | <sub>〔Ch3-2 p.43–44〕</sub> |
| Fixed points | Ax = x | (I − A)x = 0의 해. A = \[1 0; 2 1\]의 고정점은 (0, t) | <sub>〔Ch3-2 p.45–46〕</sub> |
| Nilpotent | Aᵏ = 0 | Thm 3.6.6: (I−A)⁻¹ = I + A + ⋯ + Aᵏ⁻¹ | <sub>〔Ch3-2 p.47–49〕</sub> |

Ex 4: A = \[1 3 −1; 0 2 4; 0 0 5\]는 invertible, B = \[3 −2 2; 0 0 −1; 0 0 1\]은 singular입니다. Ex 7: A = \[0 2 1; 0 0 3; 0 0 0\], A³ = 0, index of nilpotency 3, (I−A)⁻¹ = \[1 2 7; 0 1 3; 0 0 1\]. <sub>〔Ch3-2 p.39, 49〕</sub>

<details>
<summary>💡 특수 행렬 표 설명</summary>

Diagonal은 축마다 따로 늘립니다. Triangular는 대각이 모두 0이 아니어야 가역입니다. Symmetric은 대각선 거울이고, 두 대칭행렬의 곱은 AB = BA일 때만 대칭입니다. Skew-symmetric은 대각이 0입니다. AAᵀ는 크기와 무관하게 항상 대칭입니다. Fixed point는 A가 움직이지 않는 벡터로 (I − A)x = 0을 풉니다. Nilpotent는 Aᵏ = 0이고 (I − A)⁻¹이 유한 합입니다. 함정: A²이 대칭이어도 A는 대칭이 아닐 수 있습니다.

</details>
