- **Ax = b 표기** — 연립방정식을 계수 A, 미지수 x, 우변 b로 압축
- **Homogeneous** — 우변이 전부 0. x = 0이 항상 해
- **Dot product와 직교** — (1,2)·(2,−1) = 0 → 90°
- **Translation** — 모든 점에 같은 벡터를 더해 통째로 옮김. 모양은 그대로
- **Column space** — A의 열들로 만들 수 있는 모든 결합. 나올 수 있는 b의 목록
- **특수해 / 일반해** — particular = 해 하나, general = 매개변수로 모든 해를 쓴 식

### Thm 3.5.1

Ax = b가 consistent이면 해 집합은 x₀ + W입니다. x₀는 특수해, W는 Ax = 0의 해공간. <sub>〔Ch3-2 p.25〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 해 집합은 해공간을 특수해만큼 옮긴 것입니다.

**왜 쓰나** Ax = b를 Ax = 0으로 이해합니다.

**작은 예** x + y = 2: (2,0) + t(1,−1)

**함정** x₀는 아무 특수해나 됩니다.

</details>

### Thm 3.5.2

Ax = b의 일반해 = 특수해 + Ax = 0의 일반해. 예: x₀ = (0,0,0,0,0,1/3) <sub>〔Ch3-2 p.23–26〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 일반해는 특수해 하나에 동차해를 더한 것입니다.

**왜 쓰나** HW3-2 Q4의 구조입니다.

</details>

### 해 집합 분류

R²: 점, 직선, R². R³: 점, 직선, 평면, R³. <sub>〔Ch3-2 p.26〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 해 집합은 평행이동한 subspace입니다.

**왜 쓰나** Free 수로 모양을 알 수 있습니다.

</details>

### Thm 3.5.3

A가 m×n일 때 (a) Ax = 0은 trivial만 ⇔ (b) 모든 b에 Ax = b의 해가 많아야 1개. Ax = 0의 해가 무한이면 Ax = b는 해가 없거나 무한입니다. <sub>〔Ch3-2 p.27〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 서로 다른 x가 같은 값으로 가지 않으면 해는 많아야 하나입니다.

**왜 쓰나** Ax = 0의 해가 Ax = b의 해 개수를 정합니다.

**함정** Ax = 0이 무한이면 Ax = b의 해가 1개인 경우는 없습니다.

</details>

### Column space

A의 열벡터가 span하는 Rᵐ의 subspace입니다. <sub>〔Ch3-2 p.28〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** A가 만들 수 있는 출력 전체입니다.

**왜 쓰나** Ch6 range와 같습니다.

</details>

### Thm 3.5.5

Ax = b consistent ⇔ b가 A의 column space에 있음. <sub>〔Ch3-2 p.29〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** b를 열로 만들 수 있어야 해가 있습니다.

**왜 쓰나** Ax가 열의 결합이므로 정의 그대로입니다.

</details>

### Thm 3.5.6

Ax = 0의 해공간은 A의 모든 행벡터에 orthogonal한 벡터 전체입니다. <sub>〔Ch3-2 p.31–33〕</sub> → Midterm Q23–24

<details>
<summary>💡 설명</summary>

**뜻** 각 식이 "행 · x = 0"이므로 해는 모든 행에 수직입니다.

**왜 쓰나** Midterm Q23–24처럼 수직 벡터를 구할 때 씁니다.

**작은 예** x + y = 0: (1,1)·(1,−1) = 0

**함정** Ax = b (b ≠ 0)에는 해당하지 않습니다.

</details>

| x = 0 | 0 | 원점 |
| x = t₁v₁ | 1 | 원점 지나는 직선 |
| x = t₁v₁ + t₂v₂ | 2 | 원점 지나는 평면 |
| x = t₁v₁ + t₂v₂ + t₃v₃ | 3 | R³ 전체 |
