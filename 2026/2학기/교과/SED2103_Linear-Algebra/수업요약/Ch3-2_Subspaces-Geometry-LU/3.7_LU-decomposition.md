Ax = b → LUx = b → Ux = y로 두고 Ly = b를 풀어 y를 구한 뒤 Ux = y를 풉니다. <sub>〔Ch3-2 p.51〕</sub>

### Def 3.7.1

A = LU (L lower, U upper)가 LU-decomposition. 항상 존재하지도, 유일하지도 않습니다. <sub>〔Ch3-2 p.54〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** A를 아래삼각과 위삼각의 곱으로 나눕니다.

**왜 쓰나** 삼각 시스템 두 번으로 풀 수 있습니다.

**함정** \[0 1; 1 0\]처럼 LU가 없는 행렬도 있습니다.

</details>

### Thm 3.7.2

row interchange 없이 Gaussian elimination으로 REF가 되면 LU-decomposition이 존재합니다. <sub>〔Ch3-2 p.55〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 행 교환 없이 소거되면 LU가 있습니다.

**왜 쓰나** L에는 소거에 쓴 값이 기록됩니다.

**함정** 행 교환이 필요하면 PA = LU를 씁니다.

</details>

1. row interchange 없이 A를 REF U로 줄이고, leading 1을 만든 multiplier와 0을 만든 multiplier를 기록합니다.
2. L의 대각에는 leading 1을 만든 multiplier의 reciprocal을 넣습니다.
3. L의 대각 아래에는 0을 만든 multiplier의 negative를 넣습니다.
4. A = LU를 씁니다.

<sub>〔Ch3-2 p.56〕</sub>

## 비용 (flops)

| Algorithm | Cost |
|---|---|
| Gauss–Jordan forward phase (Gaussian elimination) | ≈ (2/3)n³ |
| Gauss–Jordan backward phase (back substitution) | ≈ n² |
| LU-decomposition of A | ≈ (2/3)n³ |
| Forward substitution Ly = b | ≈ n² |
| Backward substitution Ux = y | ≈ n² |
| A⁻¹ by \[A \| I\] → \[I \| A⁻¹\] | ≈ 2n³ |
| Compute A⁻¹b | ≈ 2n³ |

<sub>〔Ch3-2 p.60〕</sub>

LU와 Gaussian elimination은 같은 연산입니다 <sub>〔Ch3-2 p.59〕</sub>. 그래서 A가 꽉 찬 행렬이면 비용 절감은 크지 않습니다. 교수님은 LU의 장점을 다음으로 정리합니다. <sub>〔W9 10:24–21:46〕</sub>

- Gauss–Jordan은 b를 알아야 하지만 LU는 b가 필요 없습니다.
- A⁻¹을 더 저렴하게 구합니다. A⁻¹ = U⁻¹L⁻¹이고 삼각행렬의 역은 전체 행렬보다 쉽습니다.
- 1과 0을 저장하지 않아도 됩니다.
- L, U가 주대각 주변에 banded이면 flop이 훨씬 적습니다.

규모 감각: 10×10이 1분 걸린다고 가정하면, n을 10³배인 10⁴로 늘릴 때 O(n³)은 10⁹배가 되어 10⁹분 ≈ 1,903년입니다. MATLAB 계산 `10^9/60/24/365`. 중요한 것은 앞의 상수보다 n의 지수입니다. <sub>〔W9 13:43–17:32〕</sub>
