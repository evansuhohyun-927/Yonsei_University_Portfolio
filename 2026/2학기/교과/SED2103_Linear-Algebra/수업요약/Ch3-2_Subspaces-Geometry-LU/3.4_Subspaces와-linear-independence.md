- **Rⁿ** — 숫자 n개짜리 벡터 전체
- **스칼라배** — 각 성분에 곱합니다. 음수면 방향이 뒤집힙니다.
- **Linear combination** — 재료 v₁을 c₁스푼, v₂를 c₂스푼 섞는 레시피
- **Closed under addition** — W 안의 두 벡터를 더해도 W 안에 있음. 짝수 + 짝수 = 짝수
- **0 벡터** — 모든 성분이 0. 그림으로는 원점
- **Trivial / nontrivial** — c₁ = c₂ = ⋯ = 0은 뻔한 해, 0이 아닌 c가 있으면 nontrivial

</details>

### Def 3.4.1 Subspace

Rⁿ의 공집합 아닌 부분집합이 scalar multiplication과 addition에 닫혀 있으면 subspace입니다. {0}과 Rⁿ은 trivial subspaces입니다. 0·v = 0이므로 모든 subspace는 0을 포함합니다. <sub>〔Ch3-2 p.2–4〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 더하고 늘려도 밖으로 나가지 않는 벡터 모음입니다.

**왜 쓰나** 해공간, column space가 모두 subspace입니다.

**작은 예** y = 2x는 subspace

**함정** 먼저 0 포함 여부를 봅니다. 없으면 바로 탈락입니다.

</details>

### 반례

제1사분면(x > 0, y > 0)은 덧셈에는 닫혀 있지만 음수배에 닫혀 있지 않아 subspace가 아닙니다. <sub>〔Ch3-2 p.5〕</sub> Midterm Q21의 CMYK space도 같은 이유입니다.

<details>
<summary>💡 설명</summary>

**뜻** 스칼라배 하나로 집합 밖으로 나갑니다.

**왜 쓰나** 닫힘 조건은 두 개 모두 필요합니다.

**작은 예** (−1)(1,1) = (−1,−1)

**함정** 덧셈만 닫혀서는 부족합니다.

</details>

### Thm 3.4.2 Span

v₁,…,v<sub>s</sub>의 모든 linear combination의 집합은 subspace이며 span{v₁,…,v<sub>s</sub>}입니다. <sub>〔Ch3-2 p.6〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 벡터로 만들 수 있는 모든 결합의 모음입니다.

**왜 쓰나** Column space가 열벡터의 span입니다.

**작은 예** span{(1,0), (0,1)} = R²

**함정** Span은 항상 0을 포함합니다.

</details>

### Subspace 전체 목록

R²: {0}, 원점 지나는 직선, R². R³: {0}, 직선, 평면, R³ (모두 원점을 지남). <sub>〔Ch3-2 p.7〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** R³의 subspace는 네 종류뿐입니다.

**왜 쓰나** 도형이 원점을 지나야 합니다.

**함정** 원점을 지나지 않는 평면은 subspace가 아닙니다.

</details>

### Thm 3.4.3

Ax = 0의 해 집합은 Rⁿ의 subspace이고 solution space라 합니다. A(kx₀) = kAx₀ = 0, A(x₁+x₂) = 0 <sub>〔Ch3-2 p.8–9〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** Ax = 0의 해끼리 더하거나 배수해도 해입니다.

**왜 쓰나** 그래서 해공간이라고 부릅니다.

**함정** Ax = b (b ≠ 0)의 해집합은 subspace가 아닙니다.

</details>

### Example 5

2장의 계수행렬: solution space = span{(−3,1,0,0,0,0), (−4,0,−2,1,0,0), (−2,0,0,0,1,0)} <sub>〔Ch3-2 p.10〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** Free variable마다 벡터 하나가 나옵니다.

**왜 쓰나** 해공간의 차원이 free 수와 같습니다.

</details>

### Example 7

미지수 3개의 homogeneous system: 해공간은 원점, 직선, 평면 중 하나(A = 0이면 R³). <sub>〔Ch3-2 p.11〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 식이 늘수록 해공간이 작아집니다.

**왜 쓰나** 차원 감각을 잡는 예입니다.

</details>

### Thm 3.4.4

(a) Ax = 0의 해공간이 Rⁿ 전체 ⇔ A = 0. (b) A = B ⇔ 모든 x에 Ax = Bx. 성분을 보지 않고 행렬이 같음을 보일 수 있습니다. <sub>〔Ch3-2 p.12〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 모든 x에 대해 같게 작용하면 같은 행렬입니다.

**왜 쓰나** 성분 없이 행렬 등식을 증명합니다.

</details>

### Def 3.4.5 Independence

c₁v₁ + ⋯ + c<sub>s</sub>v<sub>s</sub> = 0의 해가 c₁ = ⋯ = c<sub>s</sub> = 0뿐이면 linearly independent, 아니면 dependent입니다. v₂ = cv₁이면 평면이 아니라 직선이 됩니다. <sub>〔Ch3-2 p.13–14〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 어느 벡터도 남는 것이 없는 상태입니다.

**왜 쓰나** Column 판정, 기저, 차원의 기초입니다.

**작은 예** (1,0), (0,1)은 independent

**함정** 0을 포함한 집합은 항상 dependent입니다.

</details>

### 기하

벡터 2개 dependent ⇔ 같은 직선(원점). 3개 dependent ⇔ 같은 평면(원점). <sub>〔Ch3-2 p.15〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** Dependent이면 도형이 한 차원 낮아집니다.

**왜 쓰나** HW3-2 Q3의 근거입니다.

</details>

### Thm 3.4.6

두 개 이상의 벡터 집합이 dependent ⇔ 그중 적어도 하나가 나머지의 linear combination. <sub>〔Ch3-2 p.16〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** Dependent이면 어떤 벡터가 나머지로 만들어집니다.

**작은 예** u − 2v + w = 0 → u = 2v − w

**함정** "적어도 하나"이지 "모두"가 아닙니다.

</details>

### Thm 3.4.7

Ax = 0이 trivial solution만 가짐 ⇔ A의 열벡터가 independent. <sub>〔Ch3-2 p.17–18〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 독립성 판정을 Ax = 0으로 바꿉니다.

**왜 쓰나** 벡터를 열로 세워 RREF를 봅니다.

</details>

### Thm 3.4.8

Rⁿ에서 n개보다 많은 벡터는 항상 dependent입니다. <sub>〔Ch3-2 p.20〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 벡터가 차원보다 많으면 남습니다.

**왜 쓰나** 계산 없이 dependent를 판정합니다.

**작은 예** R³에 벡터 4개 → dependent

**함정** n개 이하라고 independent가 보장되지는 않습니다.

</details>

Exercise: (a) independent, (b) dependent, (c) 네 벡터 in R³이므로 dependent. <sub>〔Ch3-2 p.19〕</sub>

<details>
<summary>💡 해공간 표 설명</summary>

Free variable 개수가 해공간의 차원입니다. 미지수 3개이면 0개 → 점, 1개 → 직선, 2개 → 평면, 3개 → R³입니다.

</details>
