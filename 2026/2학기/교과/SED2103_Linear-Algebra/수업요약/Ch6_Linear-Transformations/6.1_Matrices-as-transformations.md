# 6.1 Matrices as transformations

<summary>🟨 기초 Box — 처음 보는 용어 풀이</summary>

- **Function** — 입력 하나에 출력 하나를 정하는 규칙. 자판기처럼 같은 버튼이면 같은 결과가 나옵니다.
- **Domain · range** — 넣을 수 있는 입력 전체 · 실제로 나오는 출력 전체
- **Rⁿ → Rᵐ** — 숫자 n개를 넣어 숫자 m개를 받습니다. m×n 행렬은 n개를 받아 m개를 냅니다.
- **eᵢ** — i번째 성분만 1이고 나머지가 0인 벡터. R²에서 e₁ = (1,0), e₂ = (0,1)
- **왜 e만 보면 되나** — x = x₁e₁ + x₂e₂이므로 T(x) = x₁T(e₁) + x₂T(e₂). e의 도착지가 정해지면 모든 벡터가 정해집니다.
- **cos θ, sin θ** — 반지름 1인 원에서 각 θ인 점의 x좌표, y좌표

</details>

### Def 6.1.1

Function f는 domain D의 각 입력 x에 출력 f(x) 하나를 대응시키는 규칙입니다. f(x)는 x의 value 또는 image이고, 모든 출력의 집합이 range입니다. <sub>〔Ch6 p.2〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 입력 하나에 출력 하나를 정하는 규칙입니다.

**왜 쓰나** 행렬을 함수로 보는 출발점입니다.

**함정** Range는 공역 전체가 아니라 실제로 나오는 값입니다.

</details>

### Transformation

입력과 출력이 벡터인 함수입니다. w = T(x)를 x → w로 쓰고 "T maps x into w"로 읽습니다. <sub>〔Ch6 p.3〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 벡터를 넣어 벡터를 받는 함수입니다.

**왜 쓰나** Ch6 전체의 대상입니다.

</details>

### Example 1

T(x) = 2x, T(−1, 3) = (−2, 6) <sub>〔Ch6 p.4〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 모든 벡터를 2배로 늘리는 변환입니다.

**왜 쓰나** Scaling의 가장 단순한 예입니다.

</details>

### Example 2

T(x₁, x₂, x₃) = (x₁², x₂², x₃²) <sub>〔Ch6 p.5〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 성분을 제곱하는 변환입니다.

**왜 쓰나** Example 8에서 linear가 아님을 보입니다.

</details>

### Example 3

A = \[1 −1; 2 5; 3 4\]이면 T<sub>A</sub>(x₁, x₂) = (x₁ − x₂, 2x₁ + 5x₂, 3x₁ + 4x₂), T<sub>A</sub>(−1, 3) = (−4, 13, 9) <sub>〔Ch6 p.6–8〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 행렬 곱을 성분식과 점 대응으로 쓸 수 있습니다.

**왜 쓰나** 3×2 행렬은 R² → R³입니다.

**작은 예** T(−1,3) = (−1 − 3, −2 + 15, −3 + 12)

**함정** 크기 순서를 뒤집지 않습니다.

</details>

### Matrix transformation

m×n 행렬 A에 대해 T<sub>A</sub>: Rⁿ → Rᵐ, T<sub>A</sub>(x) = Ax. multiplication by A 또는 transformation A라고 부릅니다. <sub>〔Ch6 p.9〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** A를 곱하는 함수입니다.

**왜 쓰나** Ax의 해석이 그대로 함수가 됩니다.

**함정** m×n 행렬은 Rⁿ → Rᵐ입니다.

</details>

### Zero · identity

T₀(x) = 0x = 0은 zero transformation, T<sub>I</sub>(x) = Ix = x는 Rⁿ의 identity operator입니다. <sub>〔Ch6 p.10〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 모두 0으로 보내는 변환과 그대로 두는 변환입니다.

**왜 쓰나** 표준 예이자 반례 재료입니다.

</details>

### Def 6.1.2

T: Rⁿ → Rᵐ이 (i) T(cu) = cT(u) homogeneity, (ii) T(u + v) = T(u) + T(v) additivity를 만족하면 linear transformation입니다. m = n이면 linear operator입니다. 두 성질을 합치면 T(c₁v₁ + ⋯ + c<sub>k</sub>v<sub>k</sub>) = c₁T(v₁) + ⋯ + c<sub>k</sub>T(v<sub>k</sub>). <sub>〔Ch6 p.11〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 변환이 덧셈과 scalar 곱을 그대로 통과시킵니다.

**왜 쓰나** Linear이면 eᵢ의 이미지만 알면 전체가 정해집니다.

**작은 예** T(x) = 2x는 linear

**함정** 두 성질을 모두 보여야 합니다.

</details>

### Example 7

Matrix transformation은 linear입니다. A(cu) = cAu, A(u + v) = Au + Av <sub>〔Ch6 p.12〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** [Thm 3.1.5](../Ch3-1_Matrices-and-Matrix-Algebra/3.1_Operations-on-matrices.md#thm-315-linearity)가 곧 선형성입니다.

**왜 쓰나** 행렬 변환은 항상 linear입니다.

</details>

### Example 8

T(x₁, x₂, x₃) = (x₁², x₂², x₃²)는 linear가 아닙니다. T(2(1,0,0)) = (4,0,0)인데 2T(1,0,0) = (2,0,0)입니다. `보완` <sub>〔Ch6 p.13〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 반례 하나면 linear가 아닙니다.

**왜 쓰나** T(0) = 0이어도 linear가 아닐 수 있는 예입니다.

</details>

### Thm 6.1.3

Linear T이면 (a) T(0) = 0 (b) T(−u) = −T(u) (c) T(u − v) = T(u) − T(v) <sub>〔Ch6 p.14〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** Linear이면 0은 0으로 갑니다.

**왜 쓰나** T(0) ≠ 0이면 즉시 not linear입니다.

**작은 예** T(x) = x + v₀ (v₀ ≠ 0)는 not linear

**함정** T(0) = 0은 필요조건일 뿐입니다.

</details>

### Thm 6.1.4

Linear T는 T(x) = Ax로 쓸 수 있고 A = \[T(e₁) T(e₂) ⋯ T(eₙ)\]입니다. A를 standard matrix for T라고 부릅니다. <sub>〔Ch6 p.15〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** e의 도착지를 열로 세우면 행렬이 됩니다.

**왜 쓰나** Ch6의 핵심입니다. 어떤 선형변환이든 행렬로 계산합니다.

**작은 예** T(x,y) = (y,x): A = \[0 1; 1 0\]

**함정** 열에 넣습니다. 행에 넣으면 전치가 됩니다.

</details>

### Example 10

T(x) = 2x: T(e₁) = (2,0), T(e₂) = (0,2) → A = \[2 0; 0 2\] `보완` <sub>〔Ch6 p.16〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** [Thm 6.1.4](#thm-614)를 그대로 적용합니다.

**왜 쓰나** Linear 확인 → eᵢ 대입 순서입니다.

**작은 예** T(u+v) = 2u + 2v, T(cu) = c·2u

</details>

### Example 11

T(x₁, x₂, x₃) = (x₁ + x₂, x₂ − x₃): A = \[1 1 0; 0 1 −1\] `보완` <sub>〔Ch6 p.17〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** e₁, e₂, e₃를 넣어 열 3개를 만듭니다.

**왜 쓰나** 결과는 2×3입니다.

**작은 예** T(e₁) = (1,0), T(e₂) = (1,1), T(e₃) = (0,−1)

</details>

### Rotation R<sub>θ</sub>

원점 기준 반시계 θ 회전. R<sub>θ</sub> = \[cos θ −sin θ; sin θ cos θ\]. e₁ → (cos θ, sin θ), e₂ → (−sin θ, cos θ) <sub>〔Ch6 p.18〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** e₁, e₂를 θ만큼 돌린 결과가 열입니다.

**왜 쓰나** R₋θ가 Rθ의 역행렬이고, 이것이 곧 전치입니다.

**작은 예** θ = 90°: \[0 −1; 1 0\]

**함정** 반시계가 양의 방향입니다.

</details>

### Reflection H<sub>θ</sub>

원점을 지나고 x축과 각 θ인 직선에 대한 반사. H<sub>θ</sub> = \[cos 2θ sin 2θ; sin 2θ −cos 2θ\] <sub>〔Ch6 p.19〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 각 θ인 직선을 거울로 뒤집습니다.

**왜 쓰나** 열의 각도가 2θ인 이유는 e₁이 직선을 넘어가기 때문입니다.

**작은 예** θ = 45°: \[0 1; 1 0\]

**함정** θ는 직선의 각도입니다. 행렬 안의 각도는 2θ입니다.

</details>

### Unit square

꼭짓점 (0,0), (1,0), (1,1), (0,1). e₁, e₂의 image만 그려도 연산자의 동작이 보입니다. <sub>〔Ch6 p.22〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 연산자의 동작을 사각형 하나로 봅니다.

**왜 쓰나** 넓이 변화가 |det|입니다.

</details>

| Table | Operator | T(x, y) | T(e₁), T(e₂) | Standard matrix |
|---|---|---|---|---|
| 6.1.1 | y축 반사 | (−x, y) | (−1,0), (0,1) | \[−1 0; 0 1\] |
| 6.1.1 | x축 반사 | (x, −y) | (1,0), (0,−1) | \[1 0; 0 −1\] |
| 6.1.1 | y = x 반사 | (y, x) | (0,1), (1,0) | \[0 1; 1 0\] |
| 6.1.2 | x축 정사영 | (x, 0) | (1,0), (0,0) | \[1 0; 0 0\] |
| 6.1.2 | y축 정사영 | (0, y) | (0,0), (0,1) | \[0 0; 0 1\] |

<sub>〔Ch6 p.20–21〕</sub>

<details>
<summary>💡 반사·정사영 표 설명</summary>

표의 행렬 열은 T(e₁), T(e₂)입니다. 반사는 길이를 보존하고 det = −1입니다. 정사영은 한 축으로 납작해져 det = 0이고 가역이 아닙니다.

</details>

> [!NOTE]
> **맞는 진술**
> - T(0) ≠ 0이면 linear가 아님
> - Linear이면 standard matrix가 하나로 정해짐
> - Matrix transformation은 항상 linear
> - 정사영은 linear이지만 넓이가 0이 됨

> [!CAUTION]
> **흔한 오개념**
> - T(0) = 0이면 linear → 제곱 변환은 T(0) = 0이지만 linear가 아님
> - T(x) = x + v₀는 linear → 평행이동은 v₀ ≠ 0이면 T(0) ≠ 0
> - T(−v) = −T(v)면 T가 유일 → 모든 linear T가 만족
> - m×n 행렬은 Rᵐ → Rⁿ → 실제로는 Rⁿ → Rᵐ
