- **Orthogonal 복습** — u·v = 0이면 수직입니다 (Ch1).
- **Orthonormal** — 서로 수직이고 길이가 모두 1
- **Aᵀ = A⁻¹의 뜻** — 뒤집는 비용이 전치뿐입니다. 숫자를 계산할 필요 없이 행과 열만 바꾸면 역행렬입니다.
- **det와 넓이** — |det|는 넓이 배율입니다 (Ch4). 직교행렬은 넓이를 바꾸지 않아 det = ±1입니다.

</details>

### Orthogonal operator

‖T(x)‖ = ‖x‖인 linear operator입니다. Linear isometry라고도 합니다. R²의 회전과 원점을 지나는 직선에 대한 반사가 예이고, 길이와 각도를 함께 보존합니다. <sub>〔Ch6 p.24〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 길이가 변하지 않는 변환입니다.

**왜 쓰나** 회전과 반사가 대표입니다.

**함정** 정사영은 길이가 변하므로 orthogonal이 아닙니다.

</details>

### Thm 6.2.1

Linear operator T에서 (a) ‖T(x)‖ = ‖x‖ ⇔ (b) T(x)·T(y) = x·y <sub>〔Ch6 p.25〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 길이를 보존하면 내적도 보존합니다.

**왜 쓰나** Polarization identity로 증명합니다. 각도까지 유지됩니다.

</details>

### Def 6.2.2

A⁻¹ = Aᵀ인 정방행렬이 orthogonal입니다. AᵀA = I 또는 AAᵀ = I 하나만 보이면 됩니다. <sub>〔Ch6 p.26〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 전치가 곧 역행렬입니다.

**왜 쓰나** AᵀA의 (i,j) 칸은 i열과 j열의 내적입니다. 그래서 열이 orthonormal입니다.

**작은 예** \[0 −1; 1 0\]

**함정** 열이 서로 수직이기만 하면 부족하고 길이도 1이어야 합니다.

</details>

### Example 1

A = (1/7)\[3 2 6; −6 3 2; 2 6 −3\]: AᵀA = I이므로 A⁻¹ = Aᵀ = (1/7)\[3 −6 2; 2 3 6; 6 2 −3\] <sub>〔Ch6 p.27〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** AᵀA = I를 계산해 확인합니다.

**왜 쓰나** 역행렬을 전치로 바로 얻습니다.

</details>

### Thm 6.2.3

(a) orthogonal의 transpose는 orthogonal (b) inverse도 orthogonal (c) 곱도 orthogonal (d) det(A) = ±1 <sub>〔Ch6 p.28〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 전치, 역, 곱을 해도 직교행렬입니다.

**왜 쓰나** (d)는 넓이가 변하지 않는다는 뜻입니다.

**함정** det = ±1이어도 직교행렬이 아닐 수 있습니다. Shear가 반례입니다.

</details>

### Thm 6.2.5

n×n A에서 동치: (a) A orthogonal (b) ‖Ax‖ = ‖x‖ (c) Ax·Ay = x·y (d) column vectors orthonormal (e) row vectors orthonormal <sub>〔Ch6 p.29〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 직교행렬의 조건 다섯 개는 모두 같은 말입니다.

**왜 쓰나** 열 orthonormal 확인이 가장 빠릅니다.

**함정** 정방행렬에서만 성립합니다.

</details>

### Thm 6.2.6

Linear operator T가 orthogonal ⇔ T의 standard matrix가 orthogonal <sub>〔Ch6 p.30〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 연산자의 성질을 행렬로 판정합니다.

</details>

### Example 2

R<sub>θ</sub>ᵀR<sub>θ</sub> = \[cos²θ + sin²θ 0; 0 sin²θ + cos²θ\] = I. H<sub>θ</sub>ᵀH<sub>θ</sub> = I도 같습니다. <sub>〔Ch6 p.31〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** cos²θ + sin²θ = 1로 AᵀA = I가 됩니다.

**왜 쓰나** 회전과 반사가 직교행렬임을 보입니다.

</details>

### Thm 6.2.7

R²의 orthogonal linear operator의 standard matrix는 R<sub>θ</sub> = \[cos θ −sin θ; sin θ cos θ\] 또는 H<sub>θ/2</sub> = \[cos θ sin θ; sin θ −cos θ\]입니다. 회전 또는 원점을 지나는 직선에 대한 반사뿐입니다. <sub>〔Ch6 p.32〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** R²의 길이 보존 변환은 회전 아니면 반사입니다.

**왜 쓰나** det로 둘을 구분합니다.

**함정** det = 1 회전, det = −1 반사입니다.

</details>

### Example 4

det로 구분합니다. (a) \[1/√2 −1/√2; 1/√2 1/√2\]: det = 1, 회전 θ = 45°. (b) \[1/√2 1/√2; 1/√2 −1/√2\]: det = −1, 각 22.5° 직선에 대한 반사 `보완` <sub>〔Ch6 p.33〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** Det로 종류를 정한 뒤 cos, sin을 읽습니다.

**왜 쓰나** 반사선 각도는 행렬 각도의 절반입니다.

</details>

### Example 5

A₁ = \[1 2; 0 1\]: x 방향 shear k = 2. A₂ = \[2 0; 0 2\]: dilation 2. A₃ = \[2 0; 0 1\]: x 방향 expansion 2 <sub>〔Ch6 p.38〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 곱해진 위치로 종류를 판단합니다.

**왜 쓰나** 비대각이면 shear, 대각이 같으면 scaling, 다르면 방향별 확대입니다.

</details>

### Example 6

사진을 pixel 좌표와 gray level로 나누고, 좌표에 행렬을 곱한 뒤 원래 gray level을 다시 배정하면 회전·shear·압축 이미지가 됩니다. <sub>〔Ch6 p.39〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 이미지도 좌표 벡터의 모음입니다.

**왜 쓰나** MATLAB으로 좌표에 행렬을 곱합니다.

</details>

| Table | Operator | 조건 | T(x, y) | Standard matrix |
|---|---|---|---|---|
| 6.2.1 | Contraction | 0 ≤ k &lt; 1 | (kx, ky) | \[k 0; 0 k\] |
| 6.2.1 | Dilation | k > 1 | (kx, ky) | \[k 0; 0 k\] |
| 6.2.2 | x 방향 compression / expansion | 0 ≤ k &lt; 1 / k > 1 | (kx, y) | \[k 0; 0 1\] |
| 6.2.2 | y 방향 compression / expansion | 0 ≤ k &lt; 1 / k > 1 | (x, ky) | \[1 0; 0 k\] |
| 6.2.3 | x 방향 shear | k | (x + ky, y) | \[1 k; 0 1\] |
| 6.2.3 | y 방향 shear | k | (x, y + kx) | \[1 0; k 1\] |

<sub>〔Ch6 p.34–37〕</sub>

<details>
<summary>💡 Scaling·shear 표 설명</summary>

대각이 같으면 scaling, 한쪽만 다르면 방향별 압축·확대입니다. Shear는 비대각에 k가 있고 det = 1이라 넓이를 보존하지만 길이는 바꿉니다. k의 범위가 이름을 정합니다: 0 ≤ k &lt; 1이면 contraction 또는 compression, k > 1이면 dilation 또는 expansion입니다.

</details>
