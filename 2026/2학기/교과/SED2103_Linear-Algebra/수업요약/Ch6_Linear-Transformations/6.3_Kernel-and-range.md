# 6.3 Kernel and range

> **Ch6 · Linear Transformations** · 슬라이드 p.2–22  
> **선수 개념** [6.1 Matrices as transformations](6.1_Matrices-as-transformations.md) · [3.5 Geometry of linear systems](../Ch3-2_Subspaces-Geometry-LU/3.5_Geometry-of-linear-systems.md)  
> **이어지는 곳** —

**이 절의 정의·정리** [Def 6.3.1](#def-631) · [Thm 6.3.2](#thm-632) · [Thm 6.3.3](#thm-633) · [Def 6.3.4](#def-634) · [Def 6.3.6](#def-636) · [Thm 6.3.7](#thm-637) · [Def 6.3.9](#def-639) · [Def 6.3.10](#def-6310) · [Thm 6.3.11](#thm-6311) · [Thm 6.3.12](#thm-6312) · [Thm 6.3.13](#thm-6313) · [Thm 6.3.14](#thm-6314) · [Thm 6.3.15](#thm-6315)

<details>
<summary>🟨 기초 Box — 처음 보는 용어 풀이</summary>

- **Kernel** — “0으로 사라지는 입력”의 모임. 행렬이면 Ax = 0의 해 = null space
- **Range** — “도달 가능한 출력”의 모임. 행렬이면 column space
- **One-to-one** — 다른 입력 → 다른 출력. ker = {0}과 같은 말
- **Onto** — 공역 전체에 도달. 모든 b에 Ax = b 해 있음
- **rank로 판정** — m×n A: one-to-one ⇔ rank = n, onto ⇔ rank = m `보완`

</details>

### Image of a line

원점을 지나는 직선 x = tv의 image는 T(tv) = tT(v)입니다. T(v) = 0이면 점 0 하나, T(v) ≠ 0이면 T(v)가 정하는 원점 직선입니다. <sub>〔Ch6-2 p.2–3〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 원점 직선은 linear 변환 뒤에도 원점 직선이거나 한 점으로 줄어듭니다.

**왜 쓰나** 변환이 무엇을 "납작하게" 만드는지 보는 출발점입니다.

**작은 예** xy평면 정사영: z축 직선 → 점 0

**함정** T(v) = 0이면 직선 전체가 0으로 갑니다. 이것이 kernel의 아이디어입니다.

</details>

### Def 6.3.1

Linear T: Rⁿ → Rᵐ이 0으로 보내는 Rⁿ 벡터 전체를 kernel이라 하고 ker(T)로 씁니다. <sub>〔Ch6-2 p.4〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** T가 0으로 보내는 입력 전체입니다.

**왜 쓰나** 얼마나 많은 정보가 사라지는지를 잽니다. ker = {0}이면 아무것도 잃지 않습니다.

**작은 예** xy평면 정사영의 kernel = z축

**함정** 0은 항상 kernel에 들어 있습니다(T(0) = 0). 비어 있는 kernel은 없습니다.

</details>

### Ex 1 (6.3)

ker(T₀) = Rⁿ, ker(T<sub>I</sub>) = {0}, xy평면 정사영의 kernel = z축, R³ 회전의 kernel = {0}. `보완` <sub>〔Ch6-2 p.5〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 네 연산자의 kernel입니다.

**왜 쓰나** 극단(전부 사라짐, 아무것도 안 사라짐)과 중간 예를 비교합니다.

**작은 예** T₀: Rⁿ, T<sub>I</sub>: {0}, 정사영: z축, 회전: {0}

**함정** 회전은 길이를 보존하므로 0이 아닌 벡터를 0으로 보낼 수 없습니다.

</details>

### Thm 6.3.2

ker(T)는 Rⁿ의 subspace입니다. T(cu) = cT(u) = 0, T(u + v) = T(u) + T(v) = 0. <sub>〔Ch6-2 p.6〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** Kernel은 덧셈과 scalar 곱에 닫혀 있어 subspace입니다.

**왜 쓰나** Kernel을 basis와 차원으로 다룰 수 있습니다.

</details>

### Thm 6.3.3

m×n A에 대응하는 변환의 kernel은 Ax = 0의 solution space입니다. <sub>〔Ch6-2 p.7〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 행렬 변환의 kernel은 Ax = 0의 해집합입니다.

**왜 쓰나** Kernel 계산 = 동차 연립방정식 풀이(Ch2, Ch3-2 §3.5).

</details>

### Ex 2 (6.3)

A = \[1 0 0; 0 1 0; 0 0 0\]: Ax = 0 ⇔ x = y = 0, z 자유 → kernel = z축. <sub>〔Ch6-2 p.8〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 정사영 행렬로 Ax = 0을 풀면 z만 자유입니다.

**왜 쓰나** [Thm 6.3.3](#thm-633)을 계산으로 확인합니다.

**작은 예** (0, 0, 5) → (0, 0, 0)

</details>

### Def 6.3.4

Ax = 0의 solution space, 곧 T<sub>A</sub>의 kernel을 A의 null space라 하고 null(A)로 씁니다. <sub>〔Ch6-2 p.9〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** Kernel을 행렬 쪽에서 부르는 이름입니다.

**왜 쓰나** 변환 언어(ker)와 행렬 언어(null)를 연결합니다.

**작은 예** null(\[1 1; 1 1\]) = span{(1, −1)}

**함정** null(A)는 Rⁿ(열 개수 차원) 안에 있습니다.

</details>

### Ex 3 (6.3)

A = \[1 3 −2 0 2 0; 2 6 −5 −2 4 −3; 0 0 5 10 0 15; 2 6 0 8 4 18\]. RREF의 pivot은 1, 3, 6열이고 null(A) = span{(−3, 1, 0, 0, 0, 0), (−4, 0, −2, 1, 0, 0), (−2, 0, 0, 0, 1, 0)}. `보완` <sub>〔Ch6-2 p.10〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 4×6 행렬의 null space를 RREF에서 읽습니다.

**왜 쓰나** free variable 하나당 basis 벡터 하나입니다.

**작은 예** free: x₂, x₄, x₅ → 3개 벡터

**함정** pivot이 6열에도 있어 x₆ = 0입니다. free로 착각하지 않습니다.

</details>

### Def 6.3.6

Rⁿ의 벡터 하나 이상의 image가 되는 Rᵐ 벡터 전체를 range라 하고 ran(T)로 씁니다. 정의역 Rⁿ의 image입니다. <sub>〔Ch6-2 p.11〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** T로 도달할 수 있는 출력 전체입니다.

**왜 쓰나** Ax = b가 풀리는 b의 모임입니다.

**작은 예** 정사영의 range = xy평면

**함정** 공역 Rᵐ 전체와 다를 수 있습니다.

</details>

### Ex 4 (6.3)

ran(T₀) = {0}, ran(T<sub>I</sub>) = Rⁿ, xy평면 정사영의 range = xy평면, R³ 회전의 range = R³. `보완` <sub>〔Ch6-2 p.12〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 네 연산자의 range입니다.

**왜 쓰나** kernel과 반대 방향으로 비교합니다.

**작은 예** T₀: {0}, T<sub>I</sub>: Rⁿ, 정사영: xy평면, 회전: R³

**함정** Kernel이 클수록 range가 작아집니다(R³에서 dim ker + dim ran = 3). `보완`

</details>

### Thm 6.3.7

ran(T)는 Rᵐ의 subspace입니다. T<sub>A</sub>이면 ran(T<sub>A</sub>) = column space of A. `보완` <sub>〔Ch6-2 p.13〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** Range도 subspace입니다.

**왜 쓰나** T<sub>A</sub>의 range는 A의 column space입니다.

</details>

### Existence · uniqueness

Existence: 모든 Rᵐ 벡터가 image인가 (ran(T) = Rᵐ?). Uniqueness: 서로 다른 두 벡터가 같은 image를 가질 수 있는가. <sub>〔Ch6-2 p.14〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** "해가 있나?"와 "해가 하나뿐인가?"를 변환 언어로 쓴 것입니다.

**왜 쓰나** onto와 one-to-one의 동기입니다.

</details>

### Def 6.3.9

모든 Rᵐ 벡터가 적어도 한 Rⁿ 벡터의 image이면 T는 onto입니다. <sub>〔Ch6-2 p.15〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 공역의 모든 벡터에 도달합니다.

**왜 쓰나** Existence 질문의 답입니다.

**작은 예** R² 회전은 onto

**함정** Rⁿ → Rᵐ에서 n &lt; m이면 onto일 수 없습니다(열 n개로 Rᵐ을 채우지 못함). `보완`

</details>

### Def 6.3.10

서로 다른 벡터를 서로 다른 벡터로 보내면 T는 one-to-one입니다. <sub>〔Ch6-2 p.15〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 서로 다른 입력은 서로 다른 출력으로 갑니다.

**왜 쓰나** Uniqueness 질문의 답입니다.

**작은 예** shear는 one-to-one

**함정** n > m이면 one-to-one일 수 없습니다(kernel이 0이 아님). `보완`

</details>

### Thm 6.3.11

Linear T에서 (a) one-to-one ⇔ (b) ker(T) = {0}. <sub>〔Ch6-2 p.16〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** One-to-one을 kernel 하나로 판정합니다.

**왜 쓰나** 모든 쌍을 비교하지 않고 Ax = 0만 풀면 됩니다.

**작은 예** T(x₁) − T(x₂) = T(x₁ − x₂)

**함정** Linear일 때만 성립합니다.

</details>

### Thm 6.3.12

T<sub>A</sub>가 one-to-one ⇔ Ax = 0이 trivial solution만 가짐. <sub>〔Ch6-2 p.17–18〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** T<sub>A</sub> one-to-one ⇔ Ax = 0 trivial only ⇔ 열이 independent.

**왜 쓰나** rank = n(열 수)인지 보면 됩니다.

**작은 예** \[1 0; 0 1; 1 1\]: rank 2 = n → one-to-one

</details>

### Thm 6.3.13

T<sub>A</sub>가 onto ⇔ 모든 b ∈ Rᵐ에 대해 Ax = b가 consistent. <sub>〔Ch6-2 p.19–20〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** T<sub>A</sub> onto ⇔ 모든 b에 해가 있음.

**왜 쓰나** rank = m(행 수)인지 보면 됩니다.

**작은 예** \[1 0 1; 0 1 1\]: rank 2 = m → onto

</details>

### Thm 6.3.14

Linear operator T: Rⁿ → Rⁿ은 one-to-one ⇔ onto. n×n A에서는 Ax = 0이 trivial만 ⇔ 모든 b에 Ax = b consistent. <sub>〔Ch6-2 p.21〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 정방이면 one-to-one과 onto가 같은 조건입니다.

**왜 쓰나** 하나만 확인하면 됩니다.

**작은 예** det ≠ 0이면 둘 다

**함정** 정방이 아니면 성립하지 않습니다.

</details>

### Thm 6.3.15

Unifying theorem에 (k) T<sub>A</sub> one-to-one, (l) T<sub>A</sub> onto가 추가되어 (a)–(l) 12개 조건이 동치입니다. <sub>〔Ch6-2 p.22〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 가역성 동치 조건이 12개로 늘었습니다.

**왜 쓰나** T/F 문제의 근거입니다.

**작은 예** det = 0 ⇒ (k), (l) 모두 거짓

**함정** n×n일 때만 씁니다.

</details>

> 📐 **증명** → [Thm 6.3.2, 6.3.11, 6.3.14 — 증명](../증명과-풀이/Thm-6.3.2-6.3.11-6.3.14-—-증명.md)

> [!NOTE]
> **One-to-one**
> - ker(T) = {0}
> - Ax = 0은 trivial만
> - 열이 independent, rank = n
> - n ≤ m 필요

> [!CAUTION]
> **Onto**
> - ran(T) = Rᵐ
> - 모든 b에 Ax = b consistent
> - 열이 Rᵐ을 span, rank = m
> - n ≥ m 필요
