### Wireframe

Vertex(점)와 wire(선분)로 만든 도형입니다. <sub>〔Ch6-2 p.38〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 점과 선분으로 된 도형입니다.

**왜 쓰나** 변환은 점에만 적용하고 선분은 연결 정보로 다시 그립니다.

</details>

### Vertex matrix V

꼭짓점 좌표를 열로 모은 행렬. 집: V = \[0 2 3 2 0; 0 0 1 2 2\]. <sub>〔Ch6-2 p.39〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 꼭짓점 좌표를 열로 쌓은 행렬입니다.

**왜 쓰나** AV 한 번으로 모든 꼭짓점을 변환합니다.

**작은 예** 5개 꼭짓점 → 2×5

**함정** 좌표는 행이 아니라 열입니다.

</details>

### Connectivity matrix C

V의 i열 꼭짓점과 j열 꼭짓점이 연결되어 있으면 (i, j) 성분 1, 아니면 0. 항상 symmetric입니다. 슬라이드는 대각 성분을 1로 둡니다. <sub>〔Ch6-2 p.39〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 어느 꼭짓점끼리 이어져 있는지 표시합니다.

**왜 쓰나** 변환해도 C는 바뀌지 않습니다.

**작은 예** (1, 2) = 1: 1번–2번 연결

**함정** i–j 연결은 j–i 연결이므로 symmetric입니다.

</details>

### Ex 1 (6.5)

V = \[1 2 1 0; 0 1 2 1\], C = \[1 1 0 1; 1 1 1 1; 0 1 1 1; 1 1 1 1\]: 마름모와 (0, 1)–(2, 1) 대각선. <sub>〔Ch6-2 p.40〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** V와 C로 마름모 도형을 읽습니다.

</details>

### Ex 2 (6.5)

넘어진 집을 반시계 90° 회전: RV = \[0 −1; 1 0\]V = \[0 0 −1 −2 −2; 0 2 3 2 0\]. <sub>〔Ch6-2 p.41〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 회전 행렬을 V에 곱합니다.

**작은 예** (3, 1) → (−1, 3)

</details>

### Ex 3 (6.5)

Roman T를 x 방향으로 15° 기울인 italic T: S = \[1 sin 15°; 0 1\]. SV의 x좌표 = (0.50, 2.18, 4.68, 4.94, −1.06, −1.32, 1.18, −0.50), y좌표는 그대로. `보완` <sub>〔Ch6-2 p.42〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** x 방향 shear로 글자를 기울입니다.

**왜 쓰나** Italic 글꼴 생성.

**작은 예** (3, 7.5) → (4.94, 7.5)

**함정** y좌표는 변하지 않습니다.

</details>

### Homogeneous coordinates

Translation x ↦ x + x₀ (x₀ ≠ 0)는 0을 0으로 보내지 않아 linear가 아니고, 어떤 2×2 행렬로도 표현되지 않습니다. x를 (x, 1) ∈ Rⁿ⁺¹로 쓰면 행렬 곱으로 표현됩니다. <sub>〔Ch6-2 p.43〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 좌표 끝에 1을 붙여 이동도 행렬 곱으로 만듭니다.

**왜 쓰나** 회전·확대·이동을 모두 3×3 행렬 하나로 합성합니다(그래픽 엔진의 기본).

**작은 예** (2, 1) → (2, 1, 1)

**함정** 계산 후 마지막 1을 떼어야 원래 좌표입니다.

</details>

### Thm 6.5.1

\[Iₙ x₀; 0 1\]\[x; 1\] = \[x₀ + x; 1\]. <sub>〔Ch6-2 p.44〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** \[I x₀; 0 1\]이 x₀만큼 이동입니다.

**작은 예** x₀ = (3, 2): (0, 0) → (3, 2)

</details>

### Ex 5 (6.5)

Upright 집 V₁을 x₀ = (3, 2)만큼 이동: T = \[1 0 3; 0 1 2; 0 0 1\], V₂ = \[3 3 2 1 1; 2 4 5 4 2\]. <sub>〔Ch6-2 p.45–46〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 집 전체를 (3, 2)만큼 옮깁니다.

**작은 예** (−1, 3) → (2, 5)

</details>

### Size discrepancy

Rⁿ의 translation에는 (n + 1)×(n + 1) 행렬이 필요해 n×n 변환과 곱으로 합성할 수 없습니다. 그래서 모든 기본 변환을 homogeneous coordinates로 씁니다. <sub>〔Ch6-2 p.47〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 이동은 3×3, 회전은 2×2라 그대로 곱할 수 없습니다.

**왜 쓰나** 모두 homogeneous로 바꾸는 이유입니다.

</details>

### Thm 6.5.2

\[A 0; 0 1\]\[x; 1\] = \[Ax; 1\]. <sub>〔Ch6-2 p.48〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** \[A 0; 0 1\]은 A를 homogeneous로 쓴 것입니다.

</details>

### Ex 7 (6.5)

회전 후 이동을 한 번에: TR′ = \[1 0 3; 0 1 2; 0 0 1\]\[0 −1 0; 1 0 0; 0 0 1\] = \[0 −1 3; 1 0 2; 0 0 1\]. TR′V = \[3 3 2 1 1; 2 4 5 4 2; 1 1 1 1 1\]로 Ex 5와 같은 위치. <sub>〔Ch6-2 p.49–50〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 회전 후 이동 = TR′ (오른쪽 R′이 먼저).

**왜 쓰나** 한 번의 곱으로 Ex 2 + Ex 5를 합니다.

**작은 예** (3, 1) → (−1, 3) → (2, 5)

**함정** R′T로 곱하면 이동 후 회전이라 다른 위치가 됩니다.

</details>
