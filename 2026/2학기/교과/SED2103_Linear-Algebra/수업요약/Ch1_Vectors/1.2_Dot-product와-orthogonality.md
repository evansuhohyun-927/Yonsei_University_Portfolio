### Def 1.2.1 Norm

‖v‖ = √(v₁² + v₂² + ⋯ + v<sub>n</sub>²) <sub>〔Ch1 p.15〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 벡터의 길이입니다. 피타고라스 정리를 n차원으로 넓힌 식입니다.

**왜 쓰나** 거리, 단위벡터, 직교행렬의 기준입니다.

**작은 예** ‖(3,4)‖ = 5, ‖(1,2,2)‖ = 3

**함정** 성분을 더한 뒤 제곱하는 것이 아니라 각 성분을 제곱해 더합니다.

</details>

### Thm 1.2.2

(a) ‖v‖ ≥ 0 (b) ‖v‖ = 0 ⇔ v = 0 (c) ‖kv‖ = |k|‖v‖ <sub>〔Ch1 p.15〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 길이는 음수가 아니고, 0이면 영벡터뿐이며, k배 하면 길이가 |k|배입니다.

**왜 쓰나** 단위벡터를 만들 때 v/‖v‖를 씁니다.

**작은 예** ‖−2(3,4)‖ = 2·5 = 10

**함정** ‖kv‖ = k‖v‖가 아니라 절댓값 |k|입니다.

</details>

### Def 1.2.3 Distance

d(u, v) = ‖u − v‖ = √((u₁−v₁)² + ⋯ + (u<sub>n</sub>−v<sub>n</sub>)²) <sub>〔Ch1 p.16〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 두 점 사이 거리는 두 벡터 차의 길이입니다.

**왜 쓰나** 근사와 최소제곱에서 얼마나 가까운지를 재는 기준입니다.

**작은 예** d((1,1),(4,5)) = ‖(−3,−4)‖ = 5

</details>

### Thm 1.2.4

(a) d(u,v) ≥ 0 (b) d(u,v) = 0 ⇔ u = v (c) d(u,v) = d(v,u) <sub>〔Ch1 p.16〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 거리는 음수가 아니고, 같은 점일 때만 0이며, 순서와 무관합니다.

</details>

### Def 1.2.5 Dot product

u·v = u₁v₁ + ⋯ + u<sub>n</sub>v<sub>n</sub> (Euclidean inner product). v·v = ‖v‖²이므로 ‖v‖ = √(v·v). <sub>〔Ch1 p.17〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 두 벡터가 같은 방향으로 얼마나 겹치는지를 숫자 하나로 나타냅니다.

**왜 쓰나** 길이, 각도, 직교가 모두 여기서 나옵니다. 행렬 곱의 각 성분도 내적입니다.

**작은 예** (1,2)·(3,4) = 3 + 8 = 11

**함정** 결과는 벡터가 아니라 scalar입니다.

</details>

### Thm 1.2.6

(a) u·v = v·u \[symmetry\] (b) u·(v+w) = u·v + u·w \[distributive\] (c) k(u·v) = (ku)·v \[homogeneity\] (d) v·v ≥ 0, v·v = 0 ⇔ v = 0 \[positivity\] <sub>〔Ch1 p.18〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 내적은 순서를 바꿔도 같고, 덧셈과 scalar 곱을 분배할 수 있습니다.

**왜 쓰나** ‖u+v‖²를 전개할 때 씁니다.

**함정** (u·v)·w는 정의되지 않습니다. u·v가 숫자이기 때문입니다.

</details>

### Thm 1.2.7

(a) 0·v = v·0 = 0 (b) (u+v)·w = u·w + v·w (c) u·(v−w) = u·v − u·w (d) (u−v)·w = u·w − v·w (e) k(u·v) = u·(kv) <sub>〔Ch1 p.18〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 왼쪽, 오른쪽 어디서든 분배와 scalar 이동이 가능합니다.

**왜 쓰나** [Thm 1.2.6](#thm-126)과 함께 내적 전개의 근거입니다.

</details>

### Thm 1.2.8 Angle

R²·R³의 영 아닌 벡터에서 cos θ = u·v / (‖u‖‖v‖) <sub>〔Ch1 p.19〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 내적을 두 길이로 나누면 각도의 cos 값이 됩니다.

**왜 쓰나** 내적의 부호로 예각, 직각, 둔각을 판단합니다.

**작은 예** (1,0), (1,1): cos θ = 1/√2 → 45°

**함정** 영벡터에는 각도가 정의되지 않습니다.

</details>

### Def 1.2.9, 1.2.10

u·v = 0이면 orthogonal. orthogonal이고 길이가 각각 1이면 orthonormal. <sub>〔Ch1 p.19〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** Orthogonal은 수직, orthonormal은 수직이면서 길이가 1입니다.

**왜 쓰나** 직교행렬의 열이 바로 orthonormal입니다.

**작은 예** (1,0), (0,1)은 orthonormal, (2,0), (0,3)은 orthogonal만 해당

**함정** 영벡터는 모든 벡터와 orthogonal입니다.

</details>

### Thm 1.2.11 Pythagoras

u, v가 orthogonal이면 ‖u+v‖² = ‖u‖² + ‖v‖² <sub>〔Ch1 p.20〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 수직인 두 벡터의 합 길이는 직각삼각형의 빗변과 같습니다.

**왜 쓰나** 직교 분해와 최소제곱의 바탕입니다.

**작은 예** (3,0), (0,4): 5² = 9 + 16

**함정** 역도 성립합니다. 전개에서 2u·v = 0이 나오기 때문입니다.

</details>

### Thm 1.2.12 Cauchy–Schwarz

(u·v)² ≤ ‖u‖²‖v‖², 즉 |u·v| ≤ ‖u‖‖v‖ <sub>〔Ch1 p.20〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 두 벡터의 내적 크기는 길이의 곱을 넘을 수 없습니다.

**왜 쓰나** u·v = ‖u‖‖v‖cos θ이고 |cos θ| ≤ 1이기 때문입니다. 삼각부등식 증명에 쓰입니다.

**작은 예** (1,2), (3,4): 11 ≤ √5·5 ≈ 11.18

**함정** 등호는 두 벡터가 평행하거나 한쪽이 0일 때 성립합니다.

</details>

### Thm 1.2.13 Triangle

‖u+v‖ ≤ ‖u‖ + ‖v‖ <sub>〔Ch1 p.20〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 돌아가는 길은 곧장 가는 길보다 짧을 수 없습니다.

**왜 쓰나** 오차의 상한을 잡을 때 씁니다.

**작은 예** (3,0), (0,4): 5 ≤ 7

**함정** 등호는 두 벡터가 같은 방향일 때입니다.

</details>
