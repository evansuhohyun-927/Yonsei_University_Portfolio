# 1.3 직선과 평면의 벡터방정식

> **Ch1 · Vectors** · 슬라이드 p.22–25  
> **선수 개념** [1.1 벡터 연산과 Rⁿ](1.1_벡터-연산과-Rⁿ.md) · [1.2 Dot product와 orthogonality](1.2_Dot-product와-orthogonality.md)  
> **이어지는 곳** —

| 대상 | 식 | 출처 |
|---|---|---|
| 점 x₀, 방향 v의 직선 | x = x₀ + tv (−∞&lt;t&lt;∞)<br>x = x₀ + at, y = y₀ + bt | <sub>〔Ch1 p.22〕</sub> |
| 두 점을 지나는 직선 | x = x₀ + t(x₁ − x₀) | <sub>〔Ch1 p.23〕</sub> |
| 평면 (point–normal) | n·(x − x₀) = 0<br>A(x−x₀) + B(y−y₀) + C(z−z₀) = 0 | <sub>〔Ch1 p.24〕</sub> |
| 평면 (general) | Ax + By + Cz = D | <sub>〔Ch1 p.24〕</sub> |
| Rⁿ 직선 (Def 1.3.1a) | x = x₀ + tv, v ≠ 0 | <sub>〔Ch1 p.25〕</sub> |
| Rⁿ 평면 (Def 1.3.1b) | x = x₀ + t₁v₁ + t₂v₂<br>v₁, v₂는 서로 스칼라배가 아님 | <sub>〔Ch1 p.25〕</sub> |

같은 평면의 법선 n은 평면 위의 모든 방향과 직교합니다. HW1 Q6처럼 세 점이 주어지면 두 방향벡터의 cross product로 n을 구합니다. `cross`는 W4에서 다룹니다. <sub>〔W4 33:20〕</sub>

<details>
<summary>💡 직선·평면 표 설명</summary>

직선은 점 하나와 방향 하나, 평면은 점 하나와 법선 하나로 정해집니다. Rⁿ에서는 평면을 방향벡터 두 개로 씁니다. 원점을 지나면 subspace입니다.

</details>

> [!TIP]
> Direction vector는 도형을 따라가고, normal vector는 평면에 수직입니다. <sub>〔SED Atlas〕</sub>
