# 7.3 The fundamental spaces of a matrix

<details>
<summary>🟨 기초 Box — 처음 보는 용어 풀이</summary>

- **Row space** — 행들의 span. Rⁿ 안
- **Column space** — 열들의 span. Rᵐ 안. Ax의 모든 값
- **Null space** — Ax = 0의 해. Rⁿ 안
- **Orthogonal** — 내적이 0 (Ch1)
- **Ax = 0의 뜻** — A의 각 행과 x의 내적이 0. 즉 x가 모든 행과 수직

</details>

### Fundamental spaces

m×n A에 대해 row(A) ⊆ Rⁿ(행의 span), col(A) ⊆ Rᵐ(열의 span), null(A) ⊆ Rⁿ(Ax = 0의 해공간). row(Aᵀ) = col(A), col(Aᵀ) = row(A)이므로 서로 다른 것은 row(A), col(A), null(A), null(Aᵀ) 넷입니다. <sub>〔Ch7 p.27〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 행렬 하나에 붙는 네 subspace입니다.

**왜 쓰나** Ax = b의 해 구조(col)와 해의 자유도(null)를 함께 봅니다.

**작은 예** 2×3 A: row, null ⊆ R³, col, null(Aᵀ) ⊆ R²

**함정** row(A)·null(A)는 Rⁿ(열 수), col(A)·null(Aᵀ)는 Rᵐ(행 수)에 삽니다. 섞으면 차원이 틀립니다.

</details>

### Def 7.3.1

rank(A) = dim(row(A)), nullity(A) = dim(null(A)). 뒤에서 row space와 column space의 차원이 같음을 보입니다([Thm 7.5.1](7.5_The-rank-theorem-and-its-implications.md#thm-751)). <sub>〔Ch7 p.28〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** rank = row space 차원, nullity = null space 차원.

**왜 쓰나** Ax = 0의 free 변수 수가 nullity입니다.

**작은 예** \[1 2; 2 4\]: rank 1, nullity 1

**함정** rank는 0이 아닌 "행 개수"가 아니라 REF의 0 아닌 행 개수입니다.

</details>

### Def 7.3.2

Rⁿ의 공집합이 아닌 S에 대해 S⊥(orthogonal complement)는 S의 모든 벡터와 직교하는 Rⁿ 벡터 전체입니다. 벡터 하나 a이면 a⊥. <sub>〔Ch7 p.29〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** S의 모든 벡터와 수직인 벡터 전체입니다.

**왜 쓰나** Row space와 null space의 관계를 말하는 언어입니다.

**작은 예** R³에서 {e₃}⊥ = xy평면

**함정** S의 일부 벡터와만 수직이면 S⊥에 들어가지 않습니다.

</details>

### Ex 1 (7.3)

R³에서 원점 직선 L의 L⊥은 L에 수직인 원점 평면, 원점 평면 W의 W⊥은 W에 수직인 원점 직선입니다. <sub>〔Ch7 p.30〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** R³에서 직선과 평면은 서로의 ⊥입니다.

**왜 쓰나** dim L + dim L⊥ = 1 + 2 = 3을 기하로 봅니다.

</details>

### Thm 7.3.3

S가 subspace가 아니어도 S⊥은 항상 Rⁿ의 subspace입니다. <sub>〔Ch7 p.31〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** S⊥은 항상 subspace입니다.

**왜 쓰나** S가 곡선이든 점 몇 개든 ⊥은 원점을 지나는 공간입니다.

**작은 예** S = {(1, 1)} 한 점 → S⊥ = y = −x

**함정** S⊥에는 항상 0이 들어 있습니다.

</details>

### Ex 3 (7.3)

S = {(1, −2, 1), (3, −7, 5)}. S를 행으로 한 A의 Ax = 0을 풀면 x = t(3, 2, 1). S⊥은 이 방향의 원점 직선입니다. `보완` <sub>〔Ch7 p.32〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** S를 행으로 쓴 A의 null space가 S⊥입니다.

**왜 쓰나** ⊥ 계산 = Ax = 0 풀이.

**작은 예** x = t(3, 2, 1)

**함정** 검산: (3,2,1)·(1,−2,1) = 0, (3,2,1)·(3,−7,5) = 0.

</details>

### S⊥ = span(S)⊥

집합의 orthogonal complement와 그 span의 orthogonal complement는 같습니다. 행벡터 집합의 ⊥ = row space의 ⊥. <sub>〔Ch7 p.33〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 집합에 직교 = 그 span 전체에 직교.

**왜 쓰나** 행 몇 개만 확인하면 row space 전체와의 직교가 보장됩니다.

</details>

### Thm 7.3.5

m×n A에서 row(A)와 null(A)는 서로의 orthogonal complement입니다. <sub>〔Ch7 p.34〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** row(A)⊥ = null(A).

**왜 쓰나** Ax = 0은 "x가 모든 행과 수직"이라는 뜻입니다.

**작은 예** \[1 1\]: row = span(1,1), null = span(1,−1)

**함정** null(A)는 열이 아니라 행과 직교합니다.

</details>

### Thm 7.3.6

col(A)와 null(Aᵀ)는 서로의 orthogonal complement입니다(7.3.5를 Aᵀ에 적용). <sub>〔Ch7 p.35〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** col(A)⊥ = null(Aᵀ).

**왜 쓰나** b ∈ col(A) 판정을 null(Aᵀ)과의 직교로 바꿀 수 있습니다.

</details>

### 네 관계식

row(A)⊥ = null(A), null(A)⊥ = row(A), col(A)⊥ = null(Aᵀ), null(Aᵀ)⊥ = col(A). <sub>〔Ch7 p.36〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** ⊥를 두 번 하면 원래 공간입니다.

**왜 쓰나** 네 공간이 두 쌍의 직교 짝으로 정리됩니다.

</details>

### Thm 7.3.7

(a) Elementary row operation은 row space를 바꾸지 않습니다. (b) null space도 바꾸지 않습니다. (c) 어떤 row echelon form이든 0이 아닌 행들이 row space의 basis입니다. <sub>〔Ch7 p.37〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 행 연산은 row space와 null space를 보존합니다.

**왜 쓰나** REF를 구해 row space basis와 null space를 같은 행렬에서 읽습니다.

**함정** column space는 바뀝니다. 열공간 basis는 원래 A의 pivot 열에서 골라야 합니다. `보완`

</details>

### Row reduction으로 basis

S = {v₁, …, vₛ}가 span하는 W의 basis: ① vᵢ를 행으로 하는 A를 만든다 ② row echelon form으로 줄인다 ③ 0이 아닌 행을 꺼낸다. <sub>〔Ch7 p.38〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 벡터를 행으로 쌓아 REF의 0 아닌 행을 꺼냅니다.

**왜 쓰나** Span의 basis를 기계적으로 얻습니다.

**함정** 얻은 basis 벡터는 원래 vᵢ가 아닐 수 있습니다. 원래 벡터 중에서 고르려면 열로 쌓고 pivot 열을 고릅니다. `보완`

</details>

### Ex 4 (7.3)

(a) v₁ = (1, 0, 0, 0, 2), v₂ = (−2, 1, −3, −2, −4), v₃ = (0, 5, −14, −9, 0), v₄ = (2, 10, −28, −18, 4). REF의 0 아닌 행 w₁ = (1, 0, 0, 0, 2), w₂ = (0, 1, −3, −2, 0), w₃ = (0, 0, 1, 1, 0)이 W의 basis, dim W = 3. (b) W⊥ = null(A): RREF \[1 0 0 0 2; 0 1 0 1 0; 0 0 1 1 0\]에서 x₄ = s, x₅ = t → basis (0, −1, −1, 1, 0), (−2, 0, 0, 0, 1). dim W⊥ = 2. `보완` <sub>〔Ch7 p.39〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** W의 basis 3개, W⊥ = null(A)의 basis 2개입니다.

**왜 쓰나** 3 + 2 = 5 = n: 차원 정리의 예고입니다.

**작은 예** w₂ = (0, 1, −3, −2, 0)

**함정** W⊥는 A의 null space입니다. Aᵀ의 null space가 아닙니다.

</details>

### Ex 7 (7.3)

b₁ = (7, −2, 5, 3, 14), b₂ = (7, −2, 5, 3, 6), b₃ = (0, −1, 3, −2, 0) 중 span{v₁, …, v₄}에 있는 것: vᵢ를 열로 하고 bⱼ를 덧붙여 줄이면 b₁ 열만 consistent → b₁만 W에 있습니다. <sub>〔Ch7 p.40〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** b가 span 안에 있는지 = \[v₁ ⋯ v₄ | b\]가 consistent인지.

**왜 쓰나** 여러 b를 한 번에 덧붙여 동시에 판정합니다.

**작은 예** b₁만 consistent

**함정** 이번에는 v를 열로 세웁니다(결합 계수를 구하는 문제).

</details>

> [!NOTE]
> **맞는 진술**
> - row(A), null(A) ⊆ Rⁿ
> - col(A), null(Aᵀ) ⊆ Rᵐ
> - 행 연산 후에도 row space, null space 불변
> - row(A) ∩ null(A) = {0}

> [!CAUTION]
> **흔한 오개념**
> - 행 연산 후에도 column space 불변 → 바뀜, pivot 열은 원래 A에서
> - null(A)는 열과 직교 → 행과 직교
> - S⊥은 S가 subspace일 때만 subspace → 항상 subspace
> - 0 아닌 행이면 모두 row space basis → REF의 행이어야 함
