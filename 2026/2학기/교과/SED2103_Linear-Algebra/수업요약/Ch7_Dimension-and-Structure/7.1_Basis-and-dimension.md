# 7.1 Basis and dimension

<details>

- **Span 복습** — 벡터들의 linear combination 전체 (Ch3-2 §3.4)
- **Independent 복습** — c₁v₁ + ⋯ + c<sub>k</sub>v<sub>k</sub> = 0의 해가 모두 0뿐
- **Basis = 좌표축** — 공간을 덮으면서(span) 겹치지 않는(independent) 축
- **Dimension** — 축의 개수. 자유롭게 움직일 수 있는 방향 수(degrees of freedom)
- **Free 변수** — RREF에서 leading 1이 없는 열의 변수 (Ch2)

</details>

### Redundant vector

V = span{v₁, v₂, v₃}이고 v₃ = k₁v₁ + k₂v₂이면 w = c₁v₁ + c₂v₂ + c₃v₃ = (c₁ + c₃k₁)v₁ + (c₂ + c₃k₂)v₂이므로 v₃를 지워도 {v₁, v₂}가 V를 span합니다. <sub>〔Ch7 p.2〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** Dependent 집합에서는 어떤 벡터를 지워도 span이 그대로입니다.

**왜 쓰나** Basis가 "군더더기 없는 생성 집합"인 이유입니다.

**작은 예** (1,0), (0,1), (1,1)에서 (1,1)을 지워도 span = R²

**함정** 지워도 되는 벡터는 다른 벡터들의 결합인 것이어야 합니다. 아무 벡터나 지우면 안 됩니다.

</details>

### Def 7.1.1

Subspace V 안의 벡터 집합이 linearly independent이고 V를 span하면 V의 basis입니다. <sub>〔Ch7 p.3〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** Independent이면서 span하는 집합입니다.

**왜 쓰나** V의 모든 벡터를 좌표로 적는 최소한의 재료입니다.

**작은 예** R²: {(1,0), (0,1)}, {(1,1), (1,−1)} 모두 basis

**함정** span만 하거나 independent만 하면 basis가 아닙니다. 둘 다 필요합니다.

</details>

### Ex 1 (7.1)

원점 직선: 0이 아닌 벡터 하나가 basis. 원점 평면: 서로 배수가 아닌 0 아닌 두 벡터가 basis. {0}: independent 벡터가 없어 basis가 없습니다. <sub>〔Ch7 p.4〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 직선은 벡터 1개, 평면은 2개로 충분합니다.

**왜 쓰나** Basis가 하나로 정해지지 않음을 봅니다.

**작은 예** y = 2x의 basis: (1, 2) 또는 (−2, −4)

**함정** {0}에는 basis가 없습니다(0 벡터 하나는 dependent).

</details>

### Ex 2 (7.1)

c₁e₁ + ⋯ + cₙeₙ = (c₁, …, cₙ) = 0 ⇒ 모든 cᵢ = 0. e₁, …, eₙ은 independent이고 Rⁿ을 span하므로 standard basis입니다. <sub>〔Ch7 p.5〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** e₁, …, eₙ은 Rⁿ의 basis입니다.

**왜 쓰나** 좌표 (x₁, …, xₙ)가 곧 standard basis 계수입니다.

**작은 예** (3, 4) = 3e₁ + 4e₂

</details>

### Thm 7.1.2

0이 아닌 벡터 두 개 이상의 집합 S = {v₁, …, v<sub>k</sub>}가 linearly dependent ⇔ 어떤 벡터가 앞선 벡터들(predecessors)의 linear combination입니다. 나열 순서와 관계없이 성립합니다. <sub>〔Ch7 p.6〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** Dependent ⇔ 어떤 벡터가 앞 벡터들의 결합.

**왜 쓰나** 왼쪽부터 하나씩 확인하는 독립성 검사가 가능합니다.

**작은 예** (1,0), (0,1), (2,3): 세 번째 = 2e₁ + 3e₂

**함정** "모든 벡터가 결합"이 아니라 "적어도 하나"입니다. 0이 아닌 벡터 2개 이상일 때의 진술입니다.

</details>

### Ex 3 (7.1)

v₁ = (0, 2, 0), v₂ = (3, 0, 3), v₃ = (−4, 0, 4). v₂는 v₁의 배수가 아님(첫 성분 3 ≠ 0). v₃ = av₁ + bv₂ = (3b, 2a, 3b)이면 3b = −4와 3b = 4가 동시에 필요해 불가능. 따라서 independent입니다. det = −48 ≠ 0으로도 확인됩니다. `보완` <sub>〔Ch7 p.7〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 앞 벡터들로 각 벡터를 만들 수 있는지 차례로 봅니다.

**왜 쓰나** [Thm 7.1.2](#thm-712)의 사용법입니다.

**작은 예** v₃ = av₁ + bv₂를 성분으로 쓰면 3b = −4, 3b = 4

**함정** 순서를 바꿔 확인해도 결론은 같습니다.

</details>

### Ex 4 (7.1)

Row echelon form의 0이 아닌 행들은 independent입니다. 아래에서부터 나열하면 각 행의 leading 1을 앞선 행들의 결합으로 만들 수 없기 때문입니다. <sub>〔Ch7 p.8〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** REF의 0 아닌 행은 independent입니다.

**왜 쓰나** Row space basis를 바로 읽는 근거입니다([Thm 7.3.7](7.3_The-fundamental-spaces-of-a-matrix.md#thm-737)(c)).

**작은 예** \[1 2 3; 0 1 4\]의 두 행은 independent

**함정** REF가 아닌 행렬의 0 아닌 행은 dependent일 수 있습니다.

</details>

### Thm 7.1.3

(Existence of a basis) Rⁿ의 0이 아닌 subspace V에는 벡터 n개 이하로 된 basis가 존재합니다. <sub>〔Ch7 p.9〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 0이 아닌 subspace에는 항상 basis가 있고 n개 이하입니다.

**왜 쓰나** dim을 정의할 수 있는 전제입니다.

**작은 예** R³의 평면: basis 2개 ≤ 3

</details>

### Thm 7.1.4

Rⁿ의 0이 아닌 subspace의 basis는 모두 같은 개수의 벡터를 가집니다. <sub>〔Ch7 p.10〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** Basis는 여러 개지만 개수는 같습니다.

**왜 쓰나** 그래서 개수(dimension)가 subspace의 성질이 됩니다.

**작은 예** R²의 어떤 basis든 벡터 2개

**함정** 벡터 자체는 달라도 됩니다. 같은 것은 개수뿐입니다.

</details>

### Ex 5 (7.1)

원점 직선의 basis는 1개, 원점 평면은 2개, Rⁿ은 n개(standard basis가 n개이므로). <sub>〔Ch7 p.11〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 직선 1, 평면 2, Rⁿ n.

**왜 쓰나** 기하적 직관과 basis 개수가 일치합니다.

</details>

### Def 7.1.5

0이 아닌 subspace V의 dimension dim(V)는 basis 벡터의 개수입니다. dim({0}) = 0으로 정합니다. <sub>〔Ch7 p.12〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** dim(V) = basis 벡터 개수.

**왜 쓰나** Subspace의 크기를 숫자 하나로 비교합니다.

**작은 예** dim{0} = 0, dim R⁵ = 5

**함정** 벡터의 성분 개수(n)와 subspace의 dim은 다릅니다. R³ 안의 평면은 dim 2입니다.

</details>

### Ex 6 (7.1)

원점 직선 dim 1, 원점 평면 dim 2, Rⁿ dim n. <sub>〔Ch7 p.13〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** dim은 직관적인 "차원"과 같습니다.

</details>

### Canonical basis

Ax = 0을 Gauss–Jordan으로 풀어 x = t₁v₁ + ⋯ + tₛvₛ로 쓰면 v₁, …, vₛ(canonical solutions)는 independent이고 해공간을 span합니다. 이것이 해공간의 canonical basis이고 dim = s = free variable 수입니다. <sub>〔Ch7 p.14〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** Ax = 0의 일반해에서 각 free 변수 앞에 붙은 벡터들입니다.

**왜 쓰나** 해공간의 basis와 차원을 계산 없이 읽습니다.

**작은 예** x₃ = s, x₄ = t → 벡터 2개 → dim 2

**함정** dim = free 변수 수입니다. pivot 수가 아닙니다.

</details>

> 📐 **증명** → [Thm 7.1.2, 7.1.4 증명 스케치 — 증명](../증명과-풀이/Thm-7.1.2-7.1.4-증명-스케치-—-증명.md)

> [!NOTE]
> **맞는 진술**
> - Basis는 independent이고 span함
> - Basis는 여러 개, 개수는 하나
> - dim = free 변수 수(해공간)
> - {0}에는 basis가 없고 dim = 0

> [!CAUTION]
> **흔한 오개념**
> - span만 하면 basis → 군더더기가 있을 수 있음
> - R³의 평면은 dim 3 → 성분이 3개여도 dim 2
> - dim = pivot 수(해공간) → pivot 수는 rank
> - Basis는 하나뿐 → standard basis는 그중 하나
