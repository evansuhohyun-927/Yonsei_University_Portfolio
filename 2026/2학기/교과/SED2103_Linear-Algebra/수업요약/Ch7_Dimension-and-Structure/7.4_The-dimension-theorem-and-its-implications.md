# 7.4 The dimension theorem and its implications

- **rank** — REF의 0 아닌 행 수 = pivot 수
- **nullity** — free 변수 수
- **n** — 열 수 = 미지수 수

### Dimension theorem (system)

RREF에 0 아닌 행이 r개이면 Ax = 0의 free variable은 n − r개입니다. 즉 rank(A) + (free variable 수) = 열 수. <sub>〔Ch7 p.43〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** pivot 수 + free 수 = 열 수.

**왜 쓰나** [Thm 7.4.1](#thm-741)의 계산적 근거입니다.

</details>

### Thm 7.4.1

(Dimension theorem for matrices) m×n A에서 rank(A) + nullity(A) = n. <sub>〔Ch7 p.44〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** rank + nullity = n(열 수).

**왜 쓰나** 하나를 알면 다른 하나가 정해집니다.

**작은 예** 3×5 A, rank 2 → nullity 3

**함정** n은 열 수입니다. 행 수 m을 넣는 실수가 잦습니다.

</details>

### Ex 1 (7.4)

7.3 Ex 4의 A: rank 3, nullity 2 → 3 + 2 = 5 = 열 수. <sub>〔Ch7 p.45〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** [Thm 7.4.1](#thm-741)을 7.3 Ex 4로 확인합니다.

**작은 예** 3 + 2 = 5

</details>

### Basis로 확장

Independent {v₁, …, v<sub>k</sub>}를 Rⁿ의 basis로 늘리기: vᵢ를 행으로 한 A의 null space basis w<sub>k+1</sub>, …, wₙ(n − k개)을 더합니다. null(A) = row(A)⊥이므로 새 벡터가 기존 span 밖에 있습니다. <sub>〔Ch7 p.46〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** Independent 집합에 null space basis를 붙여 Rⁿ의 basis로 만듭니다.

**왜 쓰나** [Thm 7.3.5](7.3_The-fundamental-spaces-of-a-matrix.md#thm-735)(null ⊥ row)를 써서 새 벡터가 기존 span과 겹치지 않게 합니다.

</details>

### Ex 2 (7.4)

v₁ = (1, 3, −1, 1), v₂ = (0, 1, 1, 6). RREF \[1 0 −4 −17; 0 1 1 6\] → x = s(4, −1, 1, 0) + t(17, −6, 0, 1). {v₁, v₂, (4, −1, 1, 0), (17, −6, 0, 1)}이 R⁴의 basis입니다(det = 392 ≠ 0). <sub>〔Ch7 p.47–48〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** {v₁, v₂}에 null(A)의 basis 2개를 붙입니다.

**왜 쓰나** 확장 절차의 계산 예입니다.

**작은 예** det = 392 ≠ 0으로 basis 확인

**함정** 더할 벡터 수 = n − k = 2.

</details>

### Thm 7.4.2

m×n A의 rank가 k이면 (a) nullity = n − k (b) 모든 REF에 0 아닌 행 k개 (c) 0 행 m − k개 (d) Ax = 0에 pivot 변수 k개, free 변수 n − k개. <sub>〔Ch7 p.49〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** rank 하나로 REF 모양과 변수 개수가 모두 정해집니다.

**왜 쓰나** T/F 문제에서 숫자를 바로 계산합니다.

**작은 예** 4×6, rank 3 → nullity 3, 0 행 1개

**함정** 0 행 수는 m − k(행 수 기준), free 변수 수는 n − k(열 수 기준)입니다.

</details>

### Ex 3 (7.4)

5×7 A, nullity 3 → rank 4, REF의 0 행 1개, pivot 4개, free 3개. <sub>〔Ch7 p.50〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** nullity 하나로 rank와 REF 모양을 정합니다.

**작은 예** rank 4, 0 행 1, pivot 4, free 3

**함정** 0 행 수는 행 수 5에서 뺍니다.

</details>

### Thm 7.4.4

Unifying theorem 18개: (a)–(p)에 (q) rank(A) = n (r) nullity(A) = 0이 추가됩니다. <sub>〔Ch7 p.51〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 가역성 동치 조건 18개입니다.

**왜 쓰나** rank = n 하나로 모든 조건을 점검합니다.

**작은 예** rank(A) = 3인 3×3 → 18개 모두 참

**함정** 정방행렬 전용입니다.

</details>
