### proj<sub>a</sub>x 유도

x₁ = ka, x₂ = x − ka가 a와 직교해야 하므로 (x − ka)·a = 0 → k = x·a/‖a‖². 각도 θ를 구하지 않고 정사영을 계산합니다. <sub>〔Ch7-2 p.2〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** x를 a 방향 성분과 a에 수직인 성분으로 나눌 때 a 방향 성분의 배수 k = x·a/‖a‖²입니다.

**왜 쓰나** 각도를 몰라도 내적만으로 정사영을 구합니다.

**작은 예** x = (3, 4), a = (1, 0): k = 3 → (3, 0)

**함정** 분모는 ‖a‖가 아니라 ‖a‖²입니다. a가 단위벡터일 때만 (x·a)a.

</details>

### Ex 1 (7.7)

각 θ 직선 W 위 정사영의 standard matrix: u = (cos θ, sin θ)로 P<sub>θ</sub> = \[proj<sub>u</sub>e₁ proj<sub>u</sub>e₂\] = \[cos²θ sin θ cos θ; sin θ cos θ sin²θ\]. <sub>〔Ch7-2 p.3〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 각 θ 직선 위 정사영 행렬은 \[cos²θ, sinθcosθ; sinθcosθ, sin²θ\]입니다.

**왜 쓰나** Ch6의 P<sub>θ</sub>를 projection 공식으로 다시 얻습니다.

**작은 예** θ = 45°: (1/2)\[1 1; 1 1\]

**함정** P² = P이고 det P = 0(역행렬 없음).

</details>

### Thm 7.7.1

a ≠ 0이면 Rⁿ의 모든 x는 x = x₁ + x₂(x₁은 a의 배수, x₂ ⊥ a)로 정확히 한 가지로 쓰입니다. x₁ = (x·a/‖a‖²)a, x₂ = x − x₁. <sub>〔Ch7-2 p.4〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** a에 평행한 성분 + a에 수직인 성분으로의 분해는 하나뿐입니다.

**왜 쓰나** "정사영"이 잘 정의된다는 보증입니다.

**작은 예** x = (2, 1), a = (1, 1): x₁ = (3/2, 3/2), x₂ = (1/2, −1/2)

**함정** a = 0이면 성립하지 않습니다.

</details>

### Def 7.7.2

proj<sub>a</sub>x = (x·a/‖a‖²)a를 x의 a 방향 vector component, x − proj<sub>a</sub>x를 a에 직교하는 vector component라고 합니다. <sub>〔Ch7-2 p.5〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** proj<sub>a</sub>x와 x − proj<sub>a</sub>x의 이름입니다.

**작은 예** ‖proj<sub>a</sub>x‖ = |x·a|/‖a‖

</details>

### Ex 2 (7.7)

x = (2, −1, 3), a = (4, −1, 2): x·a = 15, ‖a‖² = 21 → x₁ = (20/7, −5/7, 10/7), x₂ = (−6/7, −2/7, 11/7). 검산 x₁·x₂ = 0, x₁ + x₂ = x. <sub>〔Ch7-2 p.6〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 공식에 x·a = 15, ‖a‖² = 21을 넣습니다.

**왜 쓰나** 계산 후 x₁·x₂ = 0으로 검산합니다.

**작은 예** x₁ = (15/21)a = (5/7)a

**함정** x₂는 x − x₁. 부호 실수가 잦습니다.

</details>

### Thm 7.7.4

(Projection theorem for subspaces) W가 Rⁿ의 subspace이면 모든 x는 x = x₁ + x₂(x₁ ∈ W, x₂ ∈ W⊥)로 정확히 한 가지로 쓰입니다. x₁ = proj<sub>W</sub>x, x₂ = proj<sub>W⊥</sub>x. <sub>〔Ch7-2 p.7–8〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** Subspace W에 대해서도 x = (W 성분) + (W⊥ 성분)이 유일합니다.

**왜 쓰나** 최소제곱, 최근접점 문제의 출발점입니다.

**작은 예** W = xy평면: (1, 2, 3) = (1, 2, 0) + (0, 0, 3)

**함정** W의 basis가 직교가 아니면 각 basis 방향 정사영을 더하면 안 됩니다([Thm 7.9.4](7.9_Orthonormal-bases-and-the-Gram–Schmidt-process.md#thm-794)(b)는 orthogonal basis일 때만).

</details>

### Thm 7.7.5

M의 열이 W의 basis이면 proj<sub>W</sub>x = M(MᵀM)⁻¹Mᵀx. 따라서 P = M(MᵀM)⁻¹Mᵀ가 W 위 정사영의 standard matrix입니다. <sub>〔Ch7-2 p.9〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** W 위 정사영 행렬은 P = M(MᵀM)⁻¹Mᵀ, M의 열은 W의 basis입니다.

**왜 쓰나** 어떤 basis에서도 쓸 수 있는 공식입니다.

**작은 예** M = a 하나(열 1개)면 P = aaᵀ/‖a‖²

**함정** MᵀM이 invertible이려면 M의 열이 independent여야 합니다. P는 basis 선택과 무관합니다.

</details>

### Ex 6 (7.7)

평면 x − 4y + 2z = 0: basis (4, 1, 0), (−2, 0, 1)을 M의 열로 → P = (1/21)\[20 4 −2; 4 5 8; −2 8 17\]. x = (1, 0, 4)의 정사영 = (4/7, 12/7, 22/7). 검산: P = I − nnᵀ/‖n‖², n = (1, −4, 2). `보완` <sub>〔Ch7-2 p.10〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 평면 basis 두 개로 M을 만들어 P를 구합니다.

**왜 쓰나** P = I − nnᵀ/‖n‖²로 검산할 수 있습니다.

**작은 예** Px = (4/7, 12/7, 22/7), x − Px = (3/7)(1, −4, 2) ∥ n

**함정** P는 대칭(Pᵀ = P)이고 P² = P입니다.

</details>

### Thm 7.7.7

b ∈ col(A)일 때 (a) A가 full column rank이면 Ax = b의 해는 하나이고 row(A)에 있습니다. (b) 아니면 해는 무한히 많지만 row(A)에 있는 해는 정확히 하나이고, 그 해의 norm이 가장 작습니다. <sub>〔Ch7-2 p.11〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 해가 있으면 row(A) 안의 해는 하나뿐이고 그것이 norm 최소입니다.

**왜 쓰나** 해 = x<sub>row</sub> + null(A) 원소, 두 성분이 직교라 ‖x‖² = ‖x<sub>row</sub>‖² + ‖x<sub>null</sub>‖²입니다.

**작은 예** x + y = 2: row space 해 (1, 1), norm √2가 최소

**함정** b ∉ col(A)이면 해가 없어 이 정리를 쓰지 않습니다.

</details>

> [!NOTE]
> **맞는 진술**
> - proj<sub>a</sub>x = (x·a/‖a‖²)a
> - P² = P, Pᵀ = P
> - x − proj<sub>W</sub>x ∈ W⊥
> - P = M(MᵀM)⁻¹Mᵀ는 basis 선택과 무관

> [!CAUTION]
> **흔한 오개념**
> - proj<sub>a</sub>x = (x·a/‖a‖)a → 분모는 ‖a‖²
> - P는 invertible → W ≠ Rⁿ이면 det P = 0
> - P = MMᵀ → M의 열이 orthonormal일 때만
> - 정사영 길이가 x보다 길 수 있음 → ‖proj x‖ ≤ ‖x‖
