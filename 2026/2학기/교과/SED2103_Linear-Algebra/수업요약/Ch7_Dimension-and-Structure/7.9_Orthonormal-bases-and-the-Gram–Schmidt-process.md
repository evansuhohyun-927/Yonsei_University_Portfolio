# 7.9 Orthonormal bases and the Gram–Schmidt process

> **Ch7 · Dimension and Structure** · 슬라이드 p.13–19  
> **선수 개념** [7.7 The projection theorem](7.7_The-projection-theorem.md)  
> **이어지는 곳** [7.10 QR-decomposition](7.10_QR-decomposition.md)

**이 절의 정의·정리** [Thm 7.9.1](#thm-791) · [Thm 7.9.4](#thm-794)

<details>
<summary>🟨 기초 Box — 처음 보는 용어 풀이</summary>

- **Orthogonal set** — 모든 쌍의 내적이 0
- **Orthonormal set** — Orthogonal + 각 길이 1
- **정규화** — v/‖v‖
- **정사영 공식** — proj<sub>v</sub>w = (w·v/‖v‖²)v (§7.7)

</details>

### Thm 7.9.1

0이 아닌 벡터들의 orthogonal set은 linearly independent입니다. <sub>〔Ch7-2 p.13〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 0이 아닌 orthogonal 벡터들은 independent입니다.

**왜 쓰나** 개수만 맞으면 바로 basis입니다.

**작은 예** (1, 1), (1, −1): 내적 0 → R²의 basis

**함정** 0 벡터가 끼면 성립하지 않습니다(0은 모든 벡터와 직교).

</details>

### Ex 3 (7.9)

v₁ = (3, −6, 2)/7, v₂ = (2, 3, 6)/7, v₃ = (6, 2, −3)/7: 모두 길이 1이고 서로 내적 0 → [Thm 7.9.1](#thm-791)로 independent, R³에 3개 → orthonormal basis. <sub>〔Ch7-2 p.14〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 길이 1과 서로 내적 0을 확인합니다.

**왜 쓰나** [Thm 7.9.1](#thm-791) + 개수 3 = dim R³.

**작은 예** v₁·v₂ = (6 − 18 + 12)/49 = 0

</details>

### Thm 7.9.4

(a) Orthonormal basis {v₁, …, v<sub>k</sub>}의 W에서 w = (w·v₁)v₁ + ⋯ + (w·v<sub>k</sub>)v<sub>k</sub>. (b) Orthogonal basis이면 w = Σ (w·vᵢ/‖vᵢ‖²)vᵢ. 연립방정식 없이 내적만으로 좌표를 얻습니다. <sub>〔Ch7-2 p.15〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** Orthonormal basis이면 좌표 = 내적, orthogonal basis이면 내적/‖vᵢ‖².

**왜 쓰나** 연립방정식 없이 좌표를 구합니다.

**작은 예** v = (1,1)/√2, (1,−1)/√2에서 w = (3, 1): 4/√2, 2/√2

**함정** Orthogonal이 아닌 basis에는 쓸 수 없습니다.

</details>

### Ex 8 (7.9)

w = (1, 1, 1): w·v₁ = −1/7, w·v₂ = 11/7, w·v₃ = 5/7 → w = −(1/7)v₁ + (11/7)v₂ + (5/7)v₃. <sub>〔Ch7-2 p.16〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** w와 각 vᵢ의 내적이 계수입니다.

**왜 쓰나** [Thm 7.9.4](#thm-794)(a)의 계산 예입니다.

**작은 예** w·v₁ = (3 − 6 + 2)/7 = −1/7

**함정** 검산: 계수 제곱합 = ‖w‖² = 3 (1 + 121 + 25)/49 = 3.

</details>

### Gram–Schmidt

Basis {w₁, …, w<sub>k</sub>} → orthogonal basis: v₁ = w₁, v<sub>j</sub> = w<sub>j</sub> − Σ<sub>i&lt;j</sub> (w<sub>j</sub>·vᵢ/‖vᵢ‖²)vᵢ. 각 v<sub>j</sub>는 w<sub>j</sub>에서 앞서 만든 방향 성분을 뺀 것입니다. q<sub>j</sub> = v<sub>j</sub>/‖v<sub>j</sub>‖가 orthonormal basis입니다. <sub>〔Ch7-2 p.17〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 각 w<sub>j</sub>에서 앞 vᵢ 방향 성분(정사영)을 빼서 v<sub>j</sub>를 만듭니다.

**왜 쓰나** 어떤 basis든 orthogonal/orthonormal basis로 바꿉니다. 각 단계에서 span은 그대로입니다.

**작은 예** w₁ = (1, 1), w₂ = (1, 0): v₂ = (1, 0) − (1/2)(1, 1) = (1/2, −1/2)

**함정** 빼는 것은 w<sub>j</sub>의 vᵢ 위 정사영입니다(wᵢ 위가 아님). 정규화는 마지막에 해도 됩니다.

</details>

### Ex 9 (7.9)

w₁ = (1, 1, 1), w₂ = (0, 1, 1), w₃ = (0, 0, 1) → v₁ = (1, 1, 1), v₂ = (−2/3, 1/3, 1/3), v₃ = (0, −1/2, 1/2). q₁ = (1, 1, 1)/√3, q₂ = (−2, 1, 1)/√6, q₃ = (0, −1, 1)/√2. <sub>〔Ch7-2 p.18–19〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 세 단계 Gram–Schmidt의 전체 계산입니다.

**왜 쓰나** QR(7.10 Ex 1)에 그대로 쓰입니다.

**작은 예** v₂ = (0,1,1) − (2/3)(1,1,1) = (−2/3, 1/3, 1/3)

**함정** v₃ 계산에서 v₂ 위 정사영의 분모는 ‖v₂‖² = 2/3입니다.

</details>

> [!NOTE]
> **맞는 진술**
> - Orthogonal (0 없음) ⇒ independent
> - Orthonormal basis 좌표 = 내적
> - 각 단계 span{v₁…v<sub>j</sub>} = span{w₁…w<sub>j</sub>}
> - Dependent 입력 → 어떤 v<sub>j</sub> = 0

> [!CAUTION]
> **흔한 오개념**
> - Independent ⇒ orthogonal → 역은 거짓
> - v₃ = w₃ − proj<sub>w₁</sub>w₃ − proj<sub>w₂</sub>w₃ → w가 아니라 v에 정사영
> - 정규화를 먼저 해야 함 → 마지막에 해도 같은 q
> - 순서를 바꿔도 같은 basis → 결과 basis는 순서에 따라 다름
