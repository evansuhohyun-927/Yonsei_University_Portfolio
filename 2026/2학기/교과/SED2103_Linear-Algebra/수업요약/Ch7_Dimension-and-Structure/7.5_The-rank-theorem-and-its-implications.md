### Thm 7.5.1

(Rank theorem) 행렬의 row space와 column space는 차원이 같습니다. <sub>〔Ch7 p.53〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 행으로 센 독립 개수와 열로 센 독립 개수가 같습니다.

**왜 쓰나** rank를 행 또는 열 중 편한 쪽으로 계산합니다.

**작은 예** \[1 2 3; 2 4 6\]: 행 1개, 열 1개 독립

**함정** row(A)와 col(A)의 차원이 같다는 것이지 같은 공간이라는 뜻이 아닙니다. 사는 공간부터 Rⁿ, Rᵐ으로 다릅니다.

</details>

### Ex 1 (7.5)

7.3 Ex 4의 A: Aᵀ를 REF로 줄이면 0 아닌 행 (1, −2, 0, 2), (0, 1, 5, 10), (0, 0, 1, 2) → col(A)의 basis, dim 3 = dim row(A). <sub>〔Ch7 p.54–55〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** col(A) = row(Aᵀ)이므로 Aᵀ를 줄여 열공간 basis를 얻습니다.

**왜 쓰나** Rank theorem을 계산으로 확인합니다.

**작은 예** dim 3 = dim row(A)

**함정** A의 pivot 열 (1,−2,0,2), (0,1,5,10), (0,−3,−14,−28)도 basis입니다. Basis는 하나가 아닙니다. `보완`

</details>

### Thm 7.5.2

rank(A) = rank(Aᵀ). 전치는 행과 열을 바꾸기 때문입니다. <sub>〔Ch7 p.56–57〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** rank(A) = rank(Aᵀ).

**왜 쓰나** m×n 행렬의 rank ≤ min(m, n)이 바로 나옵니다.

</details>

### 네 차원

m×n A의 rank가 k이면 dim row(A) = dim col(A) = k, dim null(A) = n − k, dim null(Aᵀ) = m − k. (rank(A) + nullity(Aᵀ) = m) <sub>〔Ch7 p.58〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** rank k 하나로 네 공간의 차원이 모두 정해집니다.

**왜 쓰나** 시험에서 가장 자주 쓰는 표입니다.

**작은 예** 3×5, rank 2 → 2, 2, 3, 1

**함정** null(Aᵀ)는 m − k(행 수 기준)입니다.

</details>

### Ex 2 (7.5)

A = \[1 2 −3 1 1; −3 1 7 −1 1; −2 3 4 0 2\]. R₂ + 3R₁, R₃ + 2R₁ → 두 행이 (0, 7, −2, 2, 4)로 같아 rank 2. dim row = dim col = 2, dim null(A) = 5 − 2 = 3, dim null(Aᵀ) = 3 − 2 = 1. <sub>〔Ch7 p.59〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 두 행이 같아지는 순간 rank 2가 보입니다.

**왜 쓰나** 끝까지 줄이지 않아도 rank를 읽습니다.

</details>

### Thm 7.5.3

(Consistency theorem) Ax = b(m개 식, n개 미지수)에서 (a) consistent ⇔ (b) b ∈ col(A) ⇔ (c) rank(A) = rank\[A | b\]. <sub>〔Ch7 p.60〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** Ax = b consistent ⇔ b ∈ col(A) ⇔ rank 불변.

**왜 쓰나** Augmented 열을 붙여 rank가 늘면 모순 행이 생긴 것입니다.

**작은 예** rank 2 → 3이면 inconsistent

**함정** rank\[A | b\]는 rank(A)보다 1 크거나 같습니다. 2 이상 커질 수 없습니다.

</details>

### Ex 3 (7.5)

4×3 계수 행렬, b = (−4, −3, 7, −1). \[A | b\]의 RREF 셋째 행이 \[0 0 0 | 1\] → rank(A) = 2, rank\[A | b\] = 3이라 inconsistent. <sub>〔Ch7 p.61〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** \[0 0 0 | 1\] 행이 rank를 하나 늘립니다.

**왜 쓰나** Consistency theorem 사용 예입니다.

</details>

### Over · underdetermined

식이 미지수보다 많으면 overdetermined, 적으면 underdetermined입니다. 공학에서는 원치 않는 물리 현상의 신호인 경우가 많습니다. <sub>〔Ch7 p.62〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 식 수와 미지수 수가 맞지 않는 시스템입니다.

**왜 쓰나** 공학 모델의 이상 신호를 진단합니다.

</details>

### Thm 7.5.6

m×n A. (a) m > n이면 어떤 b에서는 Ax = b가 inconsistent. (b) m &lt; n이면 모든 b에서 Ax = b는 inconsistent이거나 해가 무한히 많습니다. <sub>〔Ch7 p.63〕</sub>

<details>
<summary>💡 설명</summary>

**뜻** 식이 많으면 어떤 b에서 해가 없고, 미지수가 많으면 해가 0개 또는 무한입니다.

**왜 쓰나** 행렬 크기만 보고 해의 개수 범위를 압니다.

**작은 예** 2×3: 해 1개는 불가능

**함정** Overdetermined여도 특정 b에서는 해가 있을 수 있습니다. "모든 b"가 아니라 "어떤 b"입니다.

</details>

> 📐 **증명** → [Thm 7.5.3, 7.5.6 이유 — 증명](../증명과-풀이/Thm-7.5.3-7.5.6-이유-—-증명.md)

> [!NOTE]
> **m×n, rank k**
> - dim row = dim col = k
> - dim null(A) = n − k
> - dim null(Aᵀ) = m − k
> - k ≤ min(m, n)

> [!CAUTION]
> **흔한 오개념**
> - 행이 많으면 row space가 더 큼 → 항상 같은 차원
> - rank(A) = rank(Aᵀ)이면 정방 → 항상 성립
> - Overdetermined면 해가 없음 → 어떤 b에서만
> - rank\[A | b\]가 2 이상 커질 수 있음 → 최대 1
